## 技术要点

### TensorRT-LLM 部署流程

1. 检查 CUDA 环境
2. 下载/加载模型
3. 转换为 TensorRT 引擎
4. 启动推理服务器

### MCP 协议

- **Stdio 传输**: 通过子进程 stdin/stdout 通信
- **SSE 传输**: 通过 HTTP Server-Sent Events 通信
- **工具定义**: JSON Schema 格式

### SSH 命令执行

复用现有 SSH 连接模块：
```rust
let output = ssh_service.execute_command("ollama list").await?;
```

## 注意事项

1. **TensorRT-LLM 环境要求**:
   - NVIDIA GPU (Compute Capability >= 8.0)
   - CUDA >= 12.0
   - 大量显存（取决于模型大小）

2. **MCP 安全**:
   - Stdio 命令需要验证
   - 避免执行危险命令

3. **远程管理**:
   - 依赖稳定的 SSH 连接
   - 需要处理网络延迟

4. **OpenWebUI 检测**:
   - 检查常用端口 (3000, 8080)
   - 检查 Docker 容器名称
