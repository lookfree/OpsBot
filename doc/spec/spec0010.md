# SQLite 数据库完整支持设计文档

## 1. 概述

### 1.1 目标
为 ZWD-OpsBot 添加完整的 SQLite 数据库支持，实现与 MySQL 对等的功能，包括：
- 本地数据库文件打开/创建
- 表管理（创建、编辑、删除、重命名）
- 表结构编辑（列、索引、外键、检查约束、触发器）
- 数据编辑和查询
- SQL 编辑器
- ER 图设计器

### 1.2 SQLite 简介
SQLite 是一个轻量级的嵌入式关系型数据库，无需独立服务器进程，数据库存储在单个文件中。广泛应用于移动应用、桌面软件、嵌入式系统等场景。

#### 核心特点
- **零配置**：无需安装、配置或管理
- **单文件存储**：整个数据库存储在一个文件中
- **跨平台**：文件格式跨平台兼容
- **无服务器**：直接读写文件，无需网络
- **轻量级**：库文件小于 1MB
- **ACID 事务**：支持完整的事务特性

### 1.3 SQLite 与 MySQL 的主要差异

| 特性 | SQLite | MySQL |
|-----|--------|-------|
| **架构** | 嵌入式，单文件 | 客户端-服务器 |
| **连接方式** | 文件路径 | 主机:端口 |
| **认证** | 无（可选加密） | 用户名/密码 |
| **数据类型** | 动态类型（5种亲和类型） | 静态类型（多种） |
| **并发** | 写锁定整个数据库 | 行级锁 |
| **外键** | 需手动启用 | 默认支持 |
| **自增** | INTEGER PRIMARY KEY / AUTOINCREMENT | AUTO_INCREMENT |
| **标识符引用** | 双引号 `"name"` 或反引号 | 反引号 |

### 1.4 支持的 SQLite 版本
- SQLite 3.x（当前主流版本）

## 3. SQLite 数据类型

### 3.1 存储类（Storage Classes）
SQLite 使用动态类型系统，有 5 种存储类：

| 存储类 | 说明 |
|-------|------|
| NULL | 空值 |
| INTEGER | 有符号整数（1-8 字节） |
| REAL | 8 字节浮点数 |
| TEXT | UTF-8/UTF-16 字符串 |
| BLOB | 二进制数据 |

### 3.2 类型亲和性（Type Affinity）
SQLite 根据列声明类型推断亲和性：

| 声明包含 | 亲和性 | 示例 |
|---------|--------|------|
| INT | INTEGER | INT, INTEGER, TINYINT, BIGINT |
| CHAR, CLOB, TEXT | TEXT | VARCHAR(255), TEXT, CLOB |
| BLOB 或无类型 | BLOB | BLOB |
| REAL, FLOA, DOUB | REAL | REAL, DOUBLE, FLOAT |
| 其他 | NUMERIC | DECIMAL, BOOLEAN, DATE |

### 3.3 常用类型映射

| 通用类型 | SQLite 声明 | 存储亲和性 |
|---------|------------|-----------|
| 整数 | INTEGER | INTEGER |
| 小整数 | SMALLINT | INTEGER |
| 大整数 | BIGINT | INTEGER |
| 浮点数 | REAL / DOUBLE | REAL |
| 定点数 | DECIMAL(p,s) | NUMERIC |
| 字符串 | TEXT / VARCHAR(n) | TEXT |
| 二进制 | BLOB | BLOB |
| 布尔 | BOOLEAN / INTEGER | NUMERIC |
| 日期 | DATE | NUMERIC |
| 时间 | TIME | NUMERIC |
| 日期时间 | DATETIME / TIMESTAMP | NUMERIC |

```rust
// backend/src/services/database/sqlite.rs

use async_trait::async_trait;
use sqlx::{sqlite::SqlitePool, Row};
use std::sync::Arc;

use crate::models::*;
use super::traits::DatabaseDriver;

/// SQLite 数据库驱动
pub struct SqliteDriver {
    pool: SqlitePool,
    file_path: String,
}

impl SqliteDriver {
    /// 打开 SQLite 数据库文件
    pub async fn connect(file_path: &str) -> Result<Self, String> {
        // 构建连接 URL
        let url = if file_path == ":memory:" {
            "sqlite::memory:".to_string()
        } else {
            format!("sqlite://{}?mode=rwc", file_path)
        };

        let pool = SqlitePool::connect(&url)
            .await
            .map_err(|e| format!("Failed to open SQLite database: {}", e))?;

        // 启用外键支持
        sqlx::query("PRAGMA foreign_keys = ON")
            .execute(&pool)
            .await
            .map_err(|e| format!("Failed to enable foreign keys: {}", e))?;

        log::info!("Opened SQLite database: {}", file_path);

        Ok(Self {
            pool,
            file_path: file_path.to_string(),
        })
    }

    /// 测试数据库文件是否可访问
    pub async fn test_connection(file_path: &str) -> Result<(), String> {
        let url = format!("sqlite://{}?mode=ro", file_path);

        let pool = SqlitePool::connect(&url)
            .await
            .map_err(|e| format!("Cannot open database file: {}", e))?;

        // 验证数据库完整性
        sqlx::query("PRAGMA integrity_check")
            .fetch_one(&pool)
            .await
            .map_err(|e| format!("Database integrity check failed: {}", e))?;

        pool.close().await;
        Ok(())
    }

    /// 创建新的数据库文件
    pub async fn create_database(file_path: &str) -> Result<(), String> {
        let url = format!("sqlite://{}?mode=rwc", file_path);

        let pool = SqlitePool::connect(&url)
            .await
            .map_err(|e| format!("Failed to create database: {}", e))?;

        pool.close().await;
        Ok(())
    }
}

#[async_trait]
impl DatabaseDriver for SqliteDriver {
    async fn get_databases(&self) -> Result<Vec<String>, String> {
        // SQLite 单文件 = 单数据库，返回文件名
        let name = std::path::Path::new(&self.file_path)
            .file_stem()
            .and_then(|s| s.to_str())
            .unwrap_or("main")
            .to_string();
        Ok(vec![name])
    }

    async fn get_schemas(&self, _database: Option<&str>) -> Result<Vec<String>, String> {
        // SQLite 没有 schema 概念，返回 main
        Ok(vec!["main".to_string()])
    }

    async fn get_tables(
        &self,
        _database: &str,
        _schema: Option<&str>,
    ) -> Result<Vec<TableInfo>, String> {
        let sql = r#"
            SELECT name, type
            FROM sqlite_master
            WHERE type = 'table' AND name NOT LIKE 'sqlite_%'
            ORDER BY name
        "#;

        let rows = sqlx::query(sql)
            .fetch_all(&self.pool)
            .await
            .map_err(|e| e.to_string())?;

        let mut tables = Vec::new();
        for row in rows {
            let name: String = row.get("name");

            // 获取行数
            let count_sql = format!("SELECT COUNT(*) as cnt FROM \"{}\"", name);
            let count_row = sqlx::query(&count_sql)
                .fetch_one(&self.pool)
                .await
                .ok();
            let row_count = count_row.map(|r| r.get::<i64, _>("cnt") as u64);

            tables.push(TableInfo {
                name,
                table_type: "TABLE".to_string(),
                row_count,
            });
        }

        Ok(tables)
    }

    async fn get_table_structure(
        &self,
        _database: &str,
        table: &str,
    ) -> Result<TableStructure, String> {
        // 使用 PRAGMA table_info 获取列信息
        let sql = format!("PRAGMA table_info(\"{}\")", table);
        let rows = sqlx::query(&sql)
            .fetch_all(&self.pool)
            .await
            .map_err(|e| e.to_string())?;

        let mut columns = Vec::new();
        for row in rows {
            let name: String = row.get("name");
            let col_type: String = row.get("type");
            let notnull: i32 = row.get("notnull");
            let dflt_value: Option<String> = row.get("dflt_value");
            let pk: i32 = row.get("pk");

            columns.push(ColumnDetail {
                name,
                column_type: col_type,
                nullable: notnull == 0,
                key: if pk > 0 { Some("PRI".to_string()) } else { None },
                default_value: dflt_value,
                extra: None,
                comment: None,
            });
        }

        // 获取索引信息
        let idx_sql = format!("PRAGMA index_list(\"{}\")", table);
        let idx_rows = sqlx::query(&idx_sql)
            .fetch_all(&self.pool)
            .await
            .map_err(|e| e.to_string())?;

        let mut indexes = Vec::new();
        for idx_row in idx_rows {
            let idx_name: String = idx_row.get("name");
            let unique: i32 = idx_row.get("unique");

            // 获取索引列
            let col_sql = format!("PRAGMA index_info(\"{}\")", idx_name);
            let col_rows = sqlx::query(&col_sql)
                .fetch_all(&self.pool)
                .await
                .map_err(|e| e.to_string())?;

            let columns: Vec<String> = col_rows
                .iter()
                .map(|r| r.get::<String, _>("name"))
                .collect();

            indexes.push(IndexInfo {
                name: idx_name,
                columns,
                unique: unique == 1,
                index_type: "BTREE".to_string(),
            });
        }

        Ok(TableStructure {
            database: "main".to_string(),
            table_name: table.to_string(),
            columns,
            indexes,
        })
    }

    async fn get_views(
        &self,
        _database: &str,
        _schema: Option<&str>,
    ) -> Result<Vec<ViewInfo>, String> {
        let sql = r#"
            SELECT name
            FROM sqlite_master
            WHERE type = 'view'
            ORDER BY name
        "#;

        let rows = sqlx::query(sql)
            .fetch_all(&self.pool)
            .await
            .map_err(|e| e.to_string())?;

        Ok(rows
            .iter()
            .map(|row| ViewInfo {
                name: row.get("name"),
                definer: None,
                security_type: None,
            })
            .collect())
    }

    async fn get_routines(
        &self,
        _database: &str,
        _schema: Option<&str>,
    ) -> Result<Vec<RoutineInfo>, String> {
        // SQLite 不支持存储过程/函数
        Ok(vec![])
    }

    async fn get_table_ddl(
        &self,
        _database: &str,
        table: &str,
    ) -> Result<String, String> {
        let sql = "SELECT sql FROM sqlite_master WHERE type = 'table' AND name = ?";

        let row = sqlx::query(sql)
            .bind(table)
            .fetch_one(&self.pool)
            .await
            .map_err(|e| e.to_string())?;

        let ddl: String = row.get("sql");
        Ok(ddl)
    }

    async fn get_foreign_keys(
        &self,
        _database: &str,
        table: &str,
    ) -> Result<Vec<ForeignKeyInfo>, String> {
        let sql = format!("PRAGMA foreign_key_list(\"{}\")", table);
        let rows = sqlx::query(&sql)
            .fetch_all(&self.pool)
            .await
            .map_err(|e| e.to_string())?;

        Ok(rows
            .iter()
            .map(|row| ForeignKeyInfo {
                name: format!("fk_{}", row.get::<i32, _>("id")),
                column: row.get("from"),
                ref_table: row.get("table"),
                ref_column: row.get("to"),
                on_delete: row.get("on_delete"),
                on_update: row.get("on_update"),
            })
            .collect())
    }

    async fn get_check_constraints(
        &self,
        _database: &str,
        _table: &str,
    ) -> Result<Vec<CheckConstraintInfo>, String> {
        // SQLite 的 CHECK 约束需要解析 CREATE TABLE 语句
        // 简化实现：返回空列表
        Ok(vec![])
    }

    async fn get_triggers(
        &self,
        _database: &str,
        table: &str,
    ) -> Result<Vec<TriggerInfo>, String> {
        let sql = r#"
            SELECT name, sql
            FROM sqlite_master
            WHERE type = 'trigger' AND tbl_name = ?
        "#;

        let rows = sqlx::query(sql)
            .bind(table)
            .fetch_all(&self.pool)
            .await
            .map_err(|e| e.to_string())?;

        Ok(rows
            .iter()
            .map(|row| {
                let sql: String = row.get("sql");
                TriggerInfo {
                    name: row.get("name"),
                    event: "".to_string(),    // 需要解析 SQL
                    timing: "".to_string(),   // 需要解析 SQL
                    statement: sql,
                    created: None,
                }
            })
            .collect())
    }

    async fn get_table_options(
        &self,
        _database: &str,
        _table: &str,
    ) -> Result<TableOptions, String> {
        // SQLite 没有表选项
        Ok(TableOptions {
            engine: "SQLite".to_string(),
            charset: "UTF-8".to_string(),
            collation: "BINARY".to_string(),
            comment: "".to_string(),
            auto_increment: None,
            row_format: None,
        })
    }

    async fn execute_query(&self, sql: &str) -> Result<QueryResult, String> {
        let start = std::time::Instant::now();

        let rows = sqlx::query(sql)
            .fetch_all(&self.pool)
            .await
            .map_err(|e| e.to_string())?;

        let execution_time = start.elapsed().as_millis() as u64;

        if rows.is_empty() {
            return Ok(QueryResult {
                columns: vec![],
                rows: vec![],
                affected_rows: 0,
                execution_time_ms: execution_time,
            });
        }

        // 获取列信息
        let first_row = &rows[0];
        let columns: Vec<QueryColumn> = first_row
            .columns()
            .iter()
            .map(|col| QueryColumn {
                name: col.name().to_string(),
                column_type: col.type_info().to_string(),
                nullable: true,
            })
            .collect();

        // 转换行数据
        let data_rows: Vec<Vec<serde_json::Value>> = rows
            .iter()
            .map(|row| {
                columns
                    .iter()
                    .enumerate()
                    .map(|(i, _)| {
                        // 尝试获取不同类型的值
                        if let Ok(v) = row.try_get::<i64, _>(i) {
                            serde_json::Value::Number(v.into())
                        } else if let Ok(v) = row.try_get::<f64, _>(i) {
                            serde_json::Number::from_f64(v)
                                .map(serde_json::Value::Number)
                                .unwrap_or(serde_json::Value::Null)
                        } else if let Ok(v) = row.try_get::<String, _>(i) {
                            serde_json::Value::String(v)
                        } else if let Ok(v) = row.try_get::<Vec<u8>, _>(i) {
                            serde_json::Value::String(format!("[BLOB: {} bytes]", v.len()))
                        } else {
                            serde_json::Value::Null
                        }
                    })
                    .collect()
            })
            .collect();

        Ok(QueryResult {
            columns,
            rows: data_rows,
            affected_rows: 0,
            execution_time_ms: execution_time,
        })
    }

    async fn execute_update(&self, sql: &str) -> Result<QueryResult, String> {
        let start = std::time::Instant::now();

        let result = sqlx::query(sql)
            .execute(&self.pool)
            .await
            .map_err(|e| e.to_string())?;

        let execution_time = start.elapsed().as_millis() as u64;

        Ok(QueryResult {
            columns: vec![],
            rows: vec![],
            affected_rows: result.rows_affected(),
            execution_time_ms: execution_time,
        })
    }

    async fn rename_table(
        &self,
        _database: &str,
        old_name: &str,
        new_name: &str,
    ) -> Result<(), String> {
        let sql = format!("ALTER TABLE \"{}\" RENAME TO \"{}\"", old_name, new_name);
        sqlx::query(&sql)
            .execute(&self.pool)
            .await
            .map_err(|e| e.to_string())?;
        Ok(())
    }

    async fn drop_table(&self, _database: &str, table: &str) -> Result<(), String> {
        let sql = format!("DROP TABLE IF EXISTS \"{}\"", table);
        sqlx::query(&sql)
            .execute(&self.pool)
            .await
            .map_err(|e| e.to_string())?;
        Ok(())
    }

    async fn get_objects_count(
        &self,
        _database: &str,
        _schema: Option<&str>,
    ) -> Result<DatabaseObjectsCount, String> {
        let sql = r#"
            SELECT type, COUNT(*) as count
            FROM sqlite_master
            WHERE name NOT LIKE 'sqlite_%'
            GROUP BY type
        "#;

        let rows = sqlx::query(sql)
            .fetch_all(&self.pool)
            .await
            .map_err(|e| e.to_string())?;

        let mut counts = DatabaseObjectsCount {
            tables: 0,
            views: 0,
            functions: 0,
            procedures: 0,
        };

        for row in rows {
            let obj_type: String = row.get("type");
            let count: i64 = row.get("count");
            match obj_type.as_str() {
                "table" => counts.tables = count as usize,
                "view" => counts.views = count as usize,
                "trigger" => {} // 不统计触发器到 functions
                _ => {}
            }
        }

        Ok(counts)
    }

    async fn close(&self) {
        self.pool.close().await;
    }
}
```

```typescript
// front/config/datatypes/sqlite.ts

import type { DataTypeDefinition, FieldForValidation } from './types'
import { TYPE_COLORS, validators } from './base'

// SQLite 验证函数
const sqliteValidators = {
  /** SQLite 整数验证 */
  isInteger: (field: FieldForValidation): boolean => {
    return /^-?\d+$/.test(field.default)
  },

  /** SQLite 实数验证 */
  isReal: (field: FieldForValidation): boolean => {
    return /^-?\d*\.?\d+([eE][+-]?\d+)?$/.test(field.default)
  },

  /** SQLite 日期验证 */
  isDate: (field: FieldForValidation): boolean => {
    const upper = field.default.toUpperCase()
    if (['CURRENT_DATE', 'CURRENT_TIME', 'CURRENT_TIMESTAMP', 'DATE()', 'TIME()', 'DATETIME()'].includes(upper)) {
      return true
    }
    // ISO 格式日期
    return /^\d{4}-\d{2}-\d{2}/.test(field.default)
  },

  /** SQLite 布尔验证 (0 或 1) */
  isBoolean: (field: FieldForValidation): boolean => {
    const v = field.default.toLowerCase()
    return ['0', '1', 'true', 'false'].includes(v)
  },
}

/**
 * SQLite 数据类型定义
 *
 * SQLite 使用动态类型，这里定义常用的声明类型
 */
export const sqliteTypes: Record<string, DataTypeDefinition> = {
  // ==== 整数类型 (INTEGER 亲和性) ====
  INTEGER: {
    type: 'INTEGER',
    color: TYPE_COLORS.integer,
    checkDefault: sqliteValidators.isInteger,
    hasCheck: true,
    isSized: false,
    hasPrecision: false,
    canIncrement: true,  // INTEGER PRIMARY KEY 自动自增
    category: 'integer',
  },
  INT: {
    type: 'INT',
    color: TYPE_COLORS.integer,
    checkDefault: sqliteValidators.isInteger,
```

#### 4.3.4 SQL 生成器

```typescript
// front/utils/sql-generator/sqlite.ts

import type { DiagramData, TableNode, FieldNode, IndexNode, RelationshipNode } from '@/types/diagram'

/**
 * 生成 SQLite DDL
 */
export function toSQLite(diagram: DiagramData): string {
  const statements: string[] = []
  const indexStatements: string[] = []
  const fkStatements: string[] = []

  // 头部注释
  statements.push('-- SQLite DDL')
  statements.push('-- Generated by ZWD-OpsBot')
  statements.push('')

  // 启用外键
  statements.push('PRAGMA foreign_keys = ON;')
  statements.push('')

  // 生成表定义
  diagram.tables.forEach((table) => {
    const { tableSql, indexes } = generateTableSQL(table, diagram)
    statements.push(tableSql)
    indexStatements.push(...indexes)
  })

  // 生成外键（内联在 CREATE TABLE 中）
  // SQLite 外键必须在建表时定义

  return [
    ...statements,
    '',
    '-- Indexes',
    ...indexStatements,
  ].join('\n')
}

function generateTableSQL(table: TableNode, diagram: DiagramData): {
  tableSql: string
  indexes: string[]
} {
  const columns: string[] = []
  const constraints: string[] = []
  const indexes: string[] = []

  // 处理列
  table.fields.forEach((field) => {
    columns.push(generateColumnSQL(field))
  })

  // 主键约束（复合主键）
  const pkFields = table.fields.filter((f) => f.primaryKey)
  if (pkFields.length > 1) {
    // 复合主键
    const pkCols = pkFields.map((f) => `"${f.name}"`).join(', ')
    constraints.push(`PRIMARY KEY (${pkCols})`)
  }

  // 外键约束（必须在 CREATE TABLE 中定义）
  const relationships = diagram.relationships.filter(
    (r) => r.sourceTableId === table.id
  )
  relationships.forEach((rel) => {
    const fk = generateForeignKeyConstraint(rel, diagram)
    if (fk) constraints.push(fk)
  })

  // 唯一约束
  const uniqueFields = table.fields.filter((f) => f.unique && !f.primaryKey)
  uniqueFields.forEach((field) => {
    constraints.push(`UNIQUE ("${field.name}")`)
  })

  // 索引（单独生成）
  table.indexes?.forEach((idx) => {
    indexes.push(generateIndexSQL(table.name, idx))
  })

  // 组装 CREATE TABLE
  const allDefs = [...columns, ...constraints]
  const tableSql = `CREATE TABLE IF NOT EXISTS "${table.name}" (\n  ${allDefs.join(',\n  ')}\n);`

  return { tableSql, indexes }
}

function generateColumnSQL(field: FieldNode): string {
  const parts: string[] = []

  // 列名
  parts.push(`"${field.name}"`)

  // 数据类型
  parts.push(formatDataType(field))

  // INTEGER PRIMARY KEY 自动自增（SQLite 特性）
  if (field.primaryKey && field.type.toUpperCase() === 'INTEGER') {
    parts.push('PRIMARY KEY')
    if (field.autoIncrement) {
      parts.push('AUTOINCREMENT')
    }
  } else if (field.primaryKey && !hasOtherPrimaryKeys(field)) {
    parts.push('PRIMARY KEY')
  }

  // NOT NULL
  if (!field.nullable && !field.primaryKey) {
    parts.push('NOT NULL')
  }

  // 默认值
  if (field.defaultValue !== undefined && field.defaultValue !== '' && !field.autoIncrement) {
    const defaultVal = formatDefault(field)
    parts.push(`DEFAULT ${defaultVal}`)
  }

  // CHECK 约束
  if (field.check) {
    parts.push(`CHECK (${field.check})`)
  }

  return parts.join(' ')
}

function hasOtherPrimaryKeys(field: FieldNode): boolean {
  // 判断是否有其他主键列（用于复合主键）
  return false  // 简化实现
}

function formatDataType(field: FieldNode): string {
  const type = field.type.toUpperCase()

  switch (type) {
    case 'VARCHAR':
    case 'CHARACTER VARYING':
    case 'CHAR':
    case 'CHARACTER':
    case 'NCHAR':
    case 'NVARCHAR':
      return `${type}(${field.length || 255})`

    case 'DECIMAL':
    case 'NUMERIC':
      if (field.precision && field.scale !== undefined) {
        return `${type}(${field.precision}, ${field.scale})`
      } else if (field.precision) {
        return `${type}(${field.precision})`
      }
      return type

    default:
      return type
  }
}

function formatDefault(field: FieldNode): string {
  const value = field.defaultValue
  const type = field.type.toUpperCase()

  // 系统函数
  const systemFunctions = [
    'CURRENT_TIMESTAMP', 'CURRENT_DATE', 'CURRENT_TIME',
    'DATETIME()', 'DATE()', 'TIME()', 'NULL'
  ]
  if (systemFunctions.some(f => value.toUpperCase().startsWith(f.replace('()', '')))) {
    return value
  }

  // 数值类型
  const numericTypes = [
    'INTEGER', 'INT', 'TINYINT', 'SMALLINT', 'MEDIUMINT', 'BIGINT',
    'REAL', 'DOUBLE', 'FLOAT', 'NUMERIC', 'DECIMAL'
  ]
  if (numericTypes.includes(type)) {
    return value
  }

  // 布尔类型
  if (type === 'BOOLEAN') {
    return value.toLowerCase() === 'true' ? '1' : '0'
  }

  // 文本类型
  return `'${value.replace(/'/g, "''")}'`
}

function generateIndexSQL(tableName: string, index: IndexNode): string {
  const unique = index.unique ? 'UNIQUE ' : ''
  const columns = index.columns.map((c) => `"${c}"`).join(', ')

  return `CREATE ${unique}INDEX IF NOT EXISTS "${index.name}" ON "${tableName}" (${columns});`
}

function generateForeignKeyConstraint(rel: RelationshipNode, diagram: DiagramData): string | null {
  const sourceTable = diagram.tables.find((t) => t.id === rel.sourceTableId)
  const targetTable = diagram.tables.find((t) => t.id === rel.targetTableId)

  if (!sourceTable || !targetTable) return null

  const sourceField = sourceTable.fields.find((f) => f.id === rel.sourceFieldId)
  const targetField = targetTable.fields.find((f) => f.id === rel.targetFieldId)

  if (!sourceField || !targetField) return null

  let sql = `FOREIGN KEY ("${sourceField.name}") REFERENCES "${targetTable.name}" ("${targetField.name}")`

  if (rel.onDelete && rel.onDelete !== 'NO ACTION') {
    sql += ` ON DELETE ${rel.onDelete}`
  }
  if (rel.onUpdate && rel.onUpdate !== 'NO ACTION') {
    sql += ` ON UPDATE ${rel.onUpdate}`
  }

  return sql
}
```

## 7. SQLite 特有注意事项

### 7.1 ALTER TABLE 限制

SQLite 的 ALTER TABLE 支持有限：
- ✅ RENAME TABLE
- ✅ RENAME COLUMN (3.25+)
- ✅ ADD COLUMN
- ❌ DROP COLUMN (需重建表)
- ❌ 修改列类型（需重建表）
- ❌ 修改外键（需重建表）

**重建表流程**：
```sql
-- 1. 创建新表
CREATE TABLE new_table AS SELECT ... FROM old_table;
-- 2. 删除旧表
DROP TABLE old_table;
-- 3. 重命名新表
ALTER TABLE new_table RENAME TO old_table;
```

### 7.2 外键启用

SQLite 默认禁用外键约束，需要手动启用：
```sql
PRAGMA foreign_keys = ON;
```

### 7.3 并发访问

SQLite 使用文件级锁：
- 多个读取可以并发
- 写入会锁定整个数据库
- 适合单用户或低并发场景

### 7.4 文件扩展名

常见扩展名：
- `.db` - 最常见
- `.sqlite` / `.sqlite3` - 明确标识
- `.db3` - SQLite 3 格式
