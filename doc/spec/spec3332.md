#### 1.3 创建 GPU 历史记录服务
- **文件**: `backend/src/services/ai/gpu/history.rs`
- **功能**:
  ```rust
  pub struct GpuHistoryService {
      db_path: PathBuf,  // SQLite 数据库路径
  }

  impl GpuHistoryService {
      /// 初始化历史记录数据库
      pub async fn init(&self) -> Result<(), String>

      /// 保存 GPU 快照
      pub async fn save_snapshot(&self, gpu_info: &[GpuInfo]) -> Result<(), String>

      /// 获取历史数据
      pub async fn get_history(
          &self,
          gpu_index: i32,
          start_time: i64,
          end_time: i64,
          interval: HistoryInterval,
      ) -> Result<Vec<GpuHistory>, String>

      /// 清理过期数据
      pub async fn cleanup(&self, retention_days: u32) -> Result<(), String>
  }

  pub enum HistoryInterval {
      Minute,      // 1 分钟粒度
      FiveMinutes, // 5 分钟粒度
      Hour,        // 1 小时粒度
      Day,         // 1 天粒度
  }
  ```
- **数据库表结构**:
  ```sql
  CREATE TABLE IF NOT EXISTS gpu_history (
      id INTEGER PRIMARY KEY AUTOINCREMENT,
      gpu_index INTEGER NOT NULL,
      timestamp INTEGER NOT NULL,
      utilization REAL NOT NULL,
      memory_used INTEGER NOT NULL,
      memory_total INTEGER NOT NULL,
      temperature REAL NOT NULL,
      power_draw REAL,
      UNIQUE(gpu_index, timestamp)
  );

  CREATE INDEX IF NOT EXISTS idx_gpu_history_time
  ON gpu_history(gpu_index, timestamp);
  ```
- **验收标准**:
  - [ ] 数据库初始化正常
  - [ ] 快照保存正确

## 技术要点

### nvidia-smi 命令参数

```bash
# 完整查询
nvidia-smi --query-gpu=index,name,uuid,driver_version,memory.total,memory.used,memory.free,utilization.gpu,utilization.memory,temperature.gpu,power.draw,power.limit,fan.speed --format=csv,noheader,nounits

# 输出示例
0, NVIDIA GeForce RTX 4090, GPU-xxxx-xxxx, 535.154.05, 24564, 1234, 23330, 52, 12, 45, 180, 450, 30
```

### 远程监控实现

通过 SSH 连接执行 nvidia-smi 命令：
```rust
// 复用现有 SSH 连接
let ssh_service = app_state.ssh_connections.get(&ssh_connection_id);
let output = ssh_service.execute_command("nvidia-smi --query-gpu=... --format=csv").await?;
```

### 实时监控定时器

使用 `setInterval` 定时刷新：
```typescript
useEffect(() => {
  const timer = setInterval(() => {
    fetchGpuInfo()
  }, monitorInterval * 1000)
  return () => clearInterval(timer)
}, [monitorInterval])
```

## 注意事项

1. **nvidia-smi 可用性**:
   - Windows: `C:\Program Files\NVIDIA Corporation\NVSMI\nvidia-smi.exe`
   - Linux/macOS: `/usr/bin/nvidia-smi`
   - 需要检测路径是否存在

2. **数据采集频率**:
   - 默认 5 秒一次
   - 可配置 1-60 秒
   - 历史数据按分钟聚合存储

3. **显存单位**:
   - nvidia-smi 输出 MiB
   - 前端显示 GB (需转换)

4. **温度阈值**:
   - 绿色: < 60°C
   - 黄色: 60-80°C
   - 红色: > 80°C
