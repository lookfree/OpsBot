## 技术要点

### API 认证方式

| 提供商 | 认证方式 | Header |
|--------|----------|--------|
| OpenAI | Bearer Token | `Authorization: Bearer sk-xxx` |
| Claude | API Key | `x-api-key: xxx` + `anthropic-version: 2023-06-01` |
| 通义千问 | API Key | `Authorization: Bearer xxx` |

### 代理配置

```rust
// HTTP/HTTPS 代理
let proxy = reqwest::Proxy::http(&format!("http://{}:{}", host, port))?;

// SOCKS5 代理
let proxy = reqwest::Proxy::all(&format!("socks5://{}:{}", host, port))?;

// 带认证的代理
let proxy = proxy.basic_auth(&username, &password);

let client = reqwest::Client::builder()
    .proxy(proxy)
    .build()?;
```

### API Key 加密存储

使用系统 keyring 或应用数据库加密：
```rust
// 使用 AES-256 加密
fn encrypt_api_key(key: &str, app_secret: &[u8]) -> String
fn decrypt_api_key(encrypted: &str, app_secret: &[u8]) -> String
```

### 自定义 OpenAI 兼容端点

支持 LocalAI、vLLM、Ollama（OpenAI 兼容模式）等：
```typescript
const config: CloudApiConfig = {
  provider: 'custom',
  baseUrl: 'http://localhost:8080/v1',
  // ...
}
```

## 注意事项

1. **API Key 安全**:
   - 绝不在日志中打印
   - 绝不在前端明文显示
   - 存储时必须加密

2. **速率限制**:
   - 各提供商有不同的速率限制
   - 测试连接时注意不要频繁调用

3. **自定义端点**:
   - 支持 OpenAI 兼容的第三方服务
   - 支持自建的 API 代理

4. **错误消息**:
   - 显示友好的错误信息
   - 不暴露敏感信息（如完整 API Key）
