# MariaDB 完整数据库支持设计文档

## 1. 概述

### 1.1 目标
为 ZWD-OpsBot 添加完整的 MariaDB 数据库支持，实现与 MySQL 完全对等的所有功能，包括：
- 数据库连接管理
- Schema 树浏览
- 表管理（创建、编辑、删除、重命名）
- 表结构编辑（列、索引、外键、检查约束、触发器）
- 数据编辑和查询
- SQL 编辑器
- ER 图设计器

### 1.2 MariaDB 与 MySQL 的关系
MariaDB 是 MySQL 的开源分支，由 MySQL 创始人 Michael Widenius 创建。两者在核心功能上高度兼容，但 MariaDB 有以下独特特性：

- 更多的存储引擎（Aria, ColumnStore, Spider 等）
- 新的数据类型（INET4, INET6, UUID 等）
- 性能优化和安全增强
- 更好的 JSON 支持
- 支持 RETURNING 子句（10.5+）
- 支持序列（SEQUENCE）

### 3.2 后端实现

#### 3.2.1 MariaDB 驱动实现

MariaDB 使用与 MySQL 相同的协议（sqlx-mysql），因此可以复用 MySQL 的连接逻辑，主要差异在于：

1. **版本检测**: 识别 MariaDB 版本号格式（如 `10.11.6-MariaDB`）
2. **系统表查询**: 部分系统表查询语法略有不同
3. **特性支持检测**: 根据版本启用特定功能

```rust
// backend/src/services/database/mariadb.rs

use async_trait::async_trait;
use sqlx::mysql::{MySqlPool, MySqlPoolOptions};

use crate::models::*;
use super::traits::DatabaseDriver;

pub struct MariaDBDriver {
    pool: MySqlPool,
    version: MariaDBVersion,
}

#[derive(Debug, Clone)]
pub struct MariaDBVersion {
    pub major: u32,
    pub minor: u32,
    pub patch: u32,
}

impl MariaDBDriver {
    pub async fn connect(config: &DatabaseConnectRequest) -> Result<Self, String> {
        // 连接逻辑与 MySQL 类似
        // 解析版本号以识别 MariaDB 特有功能
    }

    /// 检测是否支持 RETURNING 子句
    fn supports_returning(&self) -> bool {
        self.version.major > 10 ||
        (self.version.major == 10 && self.version.minor >= 5)
    }

    /// 检测是否支持 UUID 类型
    fn supports_uuid_type(&self) -> bool {
        self.version.major > 10 ||
        (self.version.major == 10 && self.version.minor >= 7)
    }
}

#[async_trait]
impl DatabaseDriver for MariaDBDriver {
    // 实现所有 trait 方法，大部分可复用 MySQL 逻辑
}
```

import { DiagramData, TableNode } from '@/types/diagram'
import { escapeQuotes, parseDefault, parseTypeSize } from './shared'

export function toMariaDB(diagram: DiagramData): string {
  const statements: string[] = []

  // 生成表定义
  diagram.tables.forEach((table) => {
    statements.push(generateTableSQL(table, diagram))
  })

  // 生成外键约束
  const fkStatements = generateForeignKeys(diagram)
  if (fkStatements) {
    statements.push(fkStatements)
  }

  return statements.join('\n\n')
}

function generateTableSQL(table: TableNode, diagram: DiagramData): string {
  // 表定义生成逻辑，与 MySQL 类似

  const options: string[] = []
  options.push('ENGINE=InnoDB')
  options.push('DEFAULT CHARSET=utf8mb4')
  options.push('COLLATE=utf8mb4_general_ci')

  if (table.comment) {
    options.push(`COMMENT='${escapeQuotes(table.comment)}'`)
