# Redis 缓存数据库管理功能设计文档

## 1. 概述

### 1.1 目标
为 ZWD-OpsBot 添加 Redis 缓存数据库管理支持，作为中间件模块的缓存/KV存储实现。设计时需考虑：
- **复用现有架构**：使用已定义的 `MiddlewareConnection` 和 `redisConfig` 类型
- **策略模式解耦**：便于后续扩展 Memcached、KeyDB 等缓存系统
- **遵循开发规范**：函数不超过80行，单文件不超过800行
- **多模式支持**：单机、集群、哨兵三种部署模式

### 1.2 核心功能

| 功能模块 | 说明 |
|---------|------|
| 连接管理 | 单机/集群/哨兵模式、密码认证、TLS/SSL |
| 键管理 | 列表、搜索(Pattern)、类型检测、TTL、删除 |
| 数据操作 | String、List、Set、Hash、ZSet、Stream 六种类型 |
| 数据库切换 | DB0-DB15 切换（单机/哨兵模式） |
| 服务器监控 | INFO 信息、内存、连接数、QPS |
| 命令执行 | 任意 Redis 命令执行 |

### 1.3 与现有架构的集成点

| 集成点 | 现有实现 | Redis 集成方式 |
|-------|---------|---------------|
| 连接类型 | `MiddlewareConnection` | 添加 `redisConfig` 配置 |
| 连接树 | `ConnectionTree.tsx` | 在中间件节点下显示 Redis 子树 |
| 状态管理 | `connectionStore.ts` | 扩展中间件相关状态 |
| 服务层 | `services/middleware/` | 添加 Redis 驱动实现 |

### 3.2 Redis Driver 实现

```rust
// backend/src/services/middleware/redis/driver.rs

use redis::{Client, Connection, Commands, AsyncCommands};
use redis::cluster::ClusterClient;
use std::sync::Arc;
use tokio::sync::Mutex;
use crate::services::middleware::traits::*;

pub enum RedisConnection {
    Standalone(Arc<Mutex<redis::aio::MultiplexedConnection>>),
    Cluster(Arc<redis::cluster_async::ClusterConnection>),
}

pub struct RedisDriver {
    connection: RedisConnection,
    config: RedisConfig,
    current_db: Arc<Mutex<u8>>,
}

impl RedisDriver {
    pub async fn connect(config: RedisConfig) -> Result<Self, String> {
        let connection = match config.mode {
            RedisMode::Standalone => Self::connect_standalone(&config).await?,
            RedisMode::Cluster => Self::connect_cluster(&config).await?,
            RedisMode::Sentinel => Self::connect_sentinel(&config).await?,
        };

        Ok(Self {
            connection,
            config,
            current_db: Arc::new(Mutex::new(config.db.unwrap_or(0))),
        })
    }

    async fn connect_standalone(config: &RedisConfig) -> Result<RedisConnection, String> {
        let url = Self::build_connection_url(config)?;
        let client = Client::open(url)
            .map_err(|e| format!("Failed to create client: {}", e))?;

        let conn = client.get_multiplexed_async_connection().await
            .map_err(|e| format!("Failed to connect: {}", e))?;

        Ok(RedisConnection::Standalone(Arc::new(Mutex::new(conn))))
    }

    async fn connect_cluster(config: &RedisConfig) -> Result<RedisConnection, String> {
        let nodes: Vec<String> = config.nodes.clone()
            .ok_or("Cluster nodes required")?
            .iter()
            .map(|n| format!("redis://{}", n))
            .collect();

        let client = ClusterClient::new(nodes)
            .map_err(|e| format!("Failed to create cluster client: {}", e))?;

        let conn = client.get_async_connection().await
            .map_err(|e| format!("Failed to connect to cluster: {}", e))?;

        Ok(RedisConnection::Cluster(Arc::new(conn)))
    }

    async fn connect_sentinel(config: &RedisConfig) -> Result<RedisConnection, String> {
        // 哨兵模式：连接到哨兵获取主节点信息，然后连接主节点
        let sentinels = config.sentinels.as_ref()
            .ok_or("Sentinel nodes required")?;
        let master_name = config.master_name.as_ref()
            .ok_or("Master name required")?;

        // 简化实现：尝试连接第一个哨兵获取主节点
        for sentinel_addr in sentinels {
            if let Ok(master_info) = Self::get_master_from_sentinel(
                sentinel_addr,
                master_name,
                config.sentinel_password.as_deref()
            ).await {
                let mut standalone_config = config.clone();
                standalone_config.host = Some(master_info.0);
                standalone_config.port = Some(master_info.1);
                return Self::connect_standalone(&standalone_config).await;
            }
        }

        Err("Failed to connect to any sentinel".to_string())
    }

    fn build_connection_url(config: &RedisConfig) -> Result<String, String> {
        let host = config.host.as_deref().unwrap_or("127.0.0.1");
        let port = config.port.unwrap_or(6379);
        let db = config.db.unwrap_or(0);

        let mut url = if config.tls.as_ref().map(|t| t.enabled).unwrap_or(false) {
            format!("rediss://{}:{}/{}", host, port, db)
        } else {
            format!("redis://{}:{}/{}", host, port, db)
        };

        if let Some(password) = &config.password {
            url = url.replace("://", &format!(":{}@", password));
        }

        Ok(url)
    }
}

#[async_trait::async_trait]
impl CacheDriver for RedisDriver {
    async fn test_connection(&self) -> Result<RedisConnectionInfo, String> {
        let info = self.get_info(None).await?;

        Ok(RedisConnectionInfo {
            mode: info.server.redis_mode.clone(),
            version: info.server.redis_version.clone(),
            connected_clients: info.clients.connected_clients,
            used_memory: info.memory.used_memory_human.clone(),
            total_keys: info.keyspace.iter().map(|k| k.keys).sum(),
        })
    }

    async fn disconnect(&self) -> Result<(), String> {
        // redis-rs 会在 drop 时自动清理
        Ok(())
    }

    async fn get_info(&self, section: Option<&str>) -> Result<RedisInfo, String> {
        let info_str: String = match &self.connection {
            RedisConnection::Standalone(conn) => {
                let mut conn = conn.lock().await;
                if let Some(sec) = section {
                    redis::cmd("INFO").arg(sec).query_async(&mut *conn).await
                } else {
                    redis::cmd("INFO").query_async(&mut *conn).await
                }
            }
            RedisConnection::Cluster(conn) => {
                // 集群模式获取第一个节点的信息
                redis::cmd("INFO").query_async(&**conn).await
            }
        }.map_err(|e| format!("Failed to get info: {}", e))?;

        Self::parse_info(&info_str)
    }

    async fn scan_keys(&self, request: RedisScanRequest) -> Result<RedisScanResponse, String> {
        let pattern = request.pattern.as_deref().unwrap_or("*");
        let count = request.count.unwrap_or(100);

        let (new_cursor, keys): (String, Vec<String>) = match &self.connection {
            RedisConnection::Standalone(conn) => {
                let mut conn = conn.lock().await;
                let mut cmd = redis::cmd("SCAN");
                cmd.arg(&request.cursor)
                   .arg("MATCH").arg(pattern)
                   .arg("COUNT").arg(count);

                if let Some(key_type) = &request.key_type {
                    cmd.arg("TYPE").arg(key_type);
                }

                cmd.query_async(&mut *conn).await
            }
            RedisConnection::Cluster(conn) => {
                // 集群模式需要扫描所有节点
                redis::cmd("SCAN")
                    .arg(&request.cursor)
                    .arg("MATCH").arg(pattern)
                    .arg("COUNT").arg(count)
                    .query_async(&**conn).await
            }
        }.map_err(|e| format!("Scan failed: {}", e))?;

        // 获取键的元数据
        let mut key_infos = Vec::new();
        for key in keys {
            let key_type = self.get_key_type(&key).await.unwrap_or_else(|_| "unknown".to_string());
            let ttl = self.get_key_ttl(&key).await.unwrap_or(-2);
            key_infos.push(RedisKeyInfo {
                key,
                key_type,
                ttl,
                size: None,
            });
        }

        Ok(RedisScanResponse {
            cursor: new_cursor.clone(),
            keys: key_infos,
            finished: new_cursor == "0",
        })
    }

    async fn get_key_type(&self, key: &str) -> Result<String, String> {
        match &self.connection {
            RedisConnection::Standalone(conn) => {
                let mut conn = conn.lock().await;
                redis::cmd("TYPE").arg(key).query_async(&mut *conn).await
            }
            RedisConnection::Cluster(conn) => {
                redis::cmd("TYPE").arg(key).query_async(&**conn).await
            }
        }.map_err(|e| format!("Failed to get type: {}", e))
    }

    async fn get_key_ttl(&self, key: &str) -> Result<i64, String> {
        match &self.connection {
            RedisConnection::Standalone(conn) => {
                let mut conn = conn.lock().await;
                redis::cmd("TTL").arg(key).query_async(&mut *conn).await
            }
            RedisConnection::Cluster(conn) => {
                redis::cmd("TTL").arg(key).query_async(&**conn).await
            }
        }.map_err(|e| format!("Failed to get TTL: {}", e))
    }

    async fn get_value(&self, key: &str) -> Result<RedisValue, String> {
        let key_type = self.get_key_type(key).await?;

        match key_type.as_str() {
            "string" => {
                let value: String = self.execute_single_command("GET", vec![key.to_string()]).await?;
                Ok(RedisValue::String(value))
            }
            "list" => {
                let values: Vec<String> = self.execute_single_command("LRANGE", vec![
                    key.to_string(), "0".to_string(), "-1".to_string()
                ]).await?;
                Ok(RedisValue::List(values))
            }
            "set" => {
                let values: Vec<String> = self.execute_single_command("SMEMBERS", vec![key.to_string()]).await?;
                Ok(RedisValue::Set(values))
            }
            "hash" => {
                let values: Vec<(String, String)> = self.execute_hgetall(key).await?;
                Ok(RedisValue::Hash(values))
            }
            "zset" => {
                let values: Vec<(String, f64)> = self.execute_zrange_withscores(key).await?;
                Ok(RedisValue::ZSet(values))
            }
            "stream" => {
                let entries = self.execute_xrange(key).await?;
                Ok(RedisValue::Stream(entries))
            }
            "none" => Ok(RedisValue::None),
            _ => Err(format!("Unsupported type: {}", key_type)),
        }
    }

    async fn set_value(&self, request: RedisSetRequest) -> Result<(), String> {
        match request.value {
            RedisValue::String(value) => {
                let mut args = vec![request.key.clone(), value];
                if let Some(ttl) = request.ttl {
                    args.push("EX".to_string());
                    args.push(ttl.to_string());
                }
                if request.nx {
                    args.push("NX".to_string());
                }
                if request.xx {
                    args.push("XX".to_string());
                }
                self.execute_command("SET", args).await?;
            }
            RedisValue::List(values) => {
                // 先删除旧键，再添加新值
                self.execute_command("DEL", vec![request.key.clone()]).await?;
                if !values.is_empty() {
                    let mut args = vec![request.key.clone()];
                    args.extend(values);
                    self.execute_command("RPUSH", args).await?;
                }
                if let Some(ttl) = request.ttl {
                    self.set_key_ttl(&request.key, ttl).await?;
                }
            }
            RedisValue::Set(values) => {
                self.execute_command("DEL", vec![request.key.clone()]).await?;
                if !values.is_empty() {
                    let mut args = vec![request.key.clone()];
                    args.extend(values);
                    self.execute_command("SADD", args).await?;
                }
                if let Some(ttl) = request.ttl {
                    self.set_key_ttl(&request.key, ttl).await?;
                }
            }
            RedisValue::Hash(pairs) => {
                self.execute_command("DEL", vec![request.key.clone()]).await?;
                if !pairs.is_empty() {
                    let mut args = vec![request.key.clone()];
                    for (field, value) in pairs {
                        args.push(field);
                        args.push(value);
                    }
                    self.execute_command("HSET", args).await?;
                }
                if let Some(ttl) = request.ttl {
                    self.set_key_ttl(&request.key, ttl).await?;
                }
            }
            RedisValue::ZSet(members) => {
                self.execute_command("DEL", vec![request.key.clone()]).await?;
                if !members.is_empty() {
                    let mut args = vec![request.key.clone()];
                    for (member, score) in members {
                        args.push(score.to_string());
                        args.push(member);
                    }
                    self.execute_command("ZADD", args).await?;
                }
                if let Some(ttl) = request.ttl {
                    self.set_key_ttl(&request.key, ttl).await?;
                }
            }
            _ => return Err("Unsupported value type for set".to_string()),
        }
        Ok(())
    }

    async fn execute_command(&self, command: &str, args: Vec<String>) -> Result<RedisCommandResult, String> {
        let start = std::time::Instant::now();

        let result: redis::Value = match &self.connection {
            RedisConnection::Standalone(conn) => {
                let mut conn = conn.lock().await;
                let mut cmd = redis::cmd(command);
                for arg in &args {
                    cmd.arg(arg);
                }
                cmd.query_async(&mut *conn).await
            }
            RedisConnection::Cluster(conn) => {
                let mut cmd = redis::cmd(command);
                for arg in &args {
                    cmd.arg(arg);
                }
                cmd.query_async(&**conn).await
            }
        }.map_err(|e| format!("Command failed: {}", e))?;

        let execution_time_ms = start.elapsed().as_millis() as i64;

        Ok(RedisCommandResult {
            result_type: Self::get_value_type(&result),
            value: Self::redis_value_to_json(&result),
            execution_time_ms,
        })
    }

    // ... 其他方法实现
}
```

#### 3.2.1 集群模式 SCAN 分页优化

**问题背景：**

Redis 集群模式下，数据分布在多个主节点（master）上。标准的 `redis-rs` 库在集群模式下执行 SCAN 时会一次性聚合所有节点的结果，导致：
- 无法实现真正的分页
- 大量 key 时内存压力大
- 响应延迟高

**优化方案：逐节点扫描 + 复合游标**

```
┌─────────────────────────────────────────────────────────────────────────┐
│                        集群 SCAN 分页流程                                │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐                     │
│  │   Node 0    │  │   Node 1    │  │   Node 2    │  ...                │
│  │ slots 0-5460│  │slots 5461-  │  │slots 10923- │                     │
│  │             │  │    10922    │  │    16383    │                     │
│  └──────┬──────┘  └──────┬──────┘  └──────┬──────┘                     │
│         │                │                │                             │
│         ▼                ▼                ▼                             │
│  ┌─────────────────────────────────────────────────────────────────┐   │
│  │                    复合游标 (Composite Cursor)                    │   │
│  │              格式: "nodeIndex:nodeCursor"                         │   │
│  │              示例: "0:0" → "0:1234" → "1:0" → "1:5678" → ...     │   │
│  └─────────────────────────────────────────────────────────────────┘   │
│                                                                         │
│  扫描顺序:                                                              │
│  1. 从 Node 0 开始，cursor="0:0"                                        │
│  2. Node 0 返回 cursor=1234 → 下次请求 "0:1234"                         │
│  3. Node 0 返回 cursor=0 (完成) → 切换到 Node 1，cursor="1:0"           │
│  4. 重复直到所有节点扫描完成                                             │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

**数据模型扩展：**

```rust
/// 集群节点信息（用于 SCAN）
#[derive(Debug, Clone)]
pub struct ClusterNodeInfo {
    pub node_id: String,
    pub address: String,       // host:port
    pub slots: Vec<(u16, u16)>, // slot 范围列表
    pub is_master: bool,
}

/// 集群 SCAN 状态
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct ClusterScanState {
    pub node_index: usize,     // 当前扫描的节点索引
    pub node_cursor: String,   // 当前节点的 cursor
    pub total_nodes: usize,    // 主节点总数
}

impl ClusterScanState {
    /// 解析复合游标
    pub fn from_cursor(cursor: &str) -> Result<Self, String> {
        if cursor == "0" {
            return Ok(Self {
                node_index: 0,
                node_cursor: "0".to_string(),
                total_nodes: 0, // 首次扫描时填充
            });
        }

        let parts: Vec<&str> = cursor.split(':').collect();
        if parts.len() != 2 {
            return Err("Invalid cluster cursor format".to_string());
        }

        Ok(Self {
            node_index: parts[0].parse().map_err(|_| "Invalid node index")?,
            node_cursor: parts[1].to_string(),
            total_nodes: 0,
        })
    }

    /// 生成复合游标
    pub fn to_cursor(&self) -> String {
        format!("{}:{}", self.node_index, self.node_cursor)
    }

    /// 是否扫描完成
    pub fn is_finished(&self) -> bool {
        self.node_index >= self.total_nodes
    }
}
```

**实现伪代码：**

```rust
impl RedisDriver {
    /// 获取集群主节点列表
    async fn get_cluster_masters(&self) -> Result<Vec<ClusterNodeInfo>, String> {
        // 执行 CLUSTER NODES 命令
        let nodes_str: String = self.execute_raw("CLUSTER", &["NODES"]).await?;

        // 解析节点信息，过滤出 master 节点
        let masters: Vec<ClusterNodeInfo> = nodes_str
            .lines()
            .filter_map(|line| Self::parse_cluster_node(line))
            .filter(|node| node.is_master)
            .collect();

        Ok(masters)
    }

    /// 集群模式 SCAN（分页优化版）
    async fn cluster_scan_keys(&self, request: RedisScanRequest) -> Result<RedisScanResponse, String> {
        // 1. 解析复合游标
        let mut state = ClusterScanState::from_cursor(&request.cursor)?;

        // 2. 获取主节点列表
        let masters = self.get_cluster_masters().await?;
        state.total_nodes = masters.len();

        // 3. 检查是否已扫描完成
        if state.is_finished() {
            return Ok(RedisScanResponse {
                cursor: "0".to_string(),
                keys: vec![],
                finished: true,
            });
        }

        // 4. 连接当前节点执行 SCAN
        let current_node = &masters[state.node_index];
        let (new_cursor, keys) = self.scan_single_node(
            &current_node.address,
            &state.node_cursor,
            &request
        ).await?;

        // 5. 更新状态
        if new_cursor == "0" {
            // 当前节点扫描完成，移动到下一个节点
            state.node_index += 1;
            state.node_cursor = "0".to_string();
        } else {
            state.node_cursor = new_cursor;
        }

        // 6. 返回结果
        let finished = state.is_finished();
        Ok(RedisScanResponse {
            cursor: if finished { "0".to_string() } else { state.to_cursor() },
            keys: self.enrich_key_infos(keys).await?,
            finished,
        })
    }

    /// 扫描单个节点
    async fn scan_single_node(
        &self,
        node_addr: &str,
        cursor: &str,
        request: &RedisScanRequest,
    ) -> Result<(String, Vec<String>), String> {
        // 创建到指定节点的直接连接
        let client = redis::Client::open(format!("redis://{}", node_addr))
            .map_err(|e| format!("Failed to connect to node: {}", e))?;

        let mut conn = client.get_multiplexed_async_connection().await
            .map_err(|e| format!("Failed to get connection: {}", e))?;

        // 执行 SCAN
        let pattern = request.pattern.as_deref().unwrap_or("*");
        let count = request.count.unwrap_or(100);

        let mut cmd = redis::cmd("SCAN");
        cmd.arg(cursor).arg("MATCH").arg(pattern).arg("COUNT").arg(count);

        if let Some(key_type) = &request.key_type {
            cmd.arg("TYPE").arg(key_type);
        }

        cmd.query_async::<(String, Vec<String>)>(&mut conn)
            .await
            .map_err(|e| format!("SCAN failed: {}", e))
    }
}
```

**前端处理（无需修改）：**

前端代码无需修改，因为：
- `cursor` 仍是字符串类型，对前端透明
- `finished` 标志仍正常工作
- 分页逻辑（"加载更多"按钮）保持不变

**性能对比：**

| 指标 | 优化前 | 优化后 |
|------|--------|--------|
| 首次响应 | 慢（需聚合所有节点） | 快（只扫描第一个节点） |
| 内存占用 | 高（全部 key 加载） | 低（每次只加载一批） |
| 分页支持 | 无（一次性返回） | 有（真正的增量加载） |
| 用户体验 | 大集群下卡顿 | 流畅的渐进加载 |

**注意事项：**
- 节点故障时需要跳过并记录错误
- 集群拓扑变化时游标可能失效，需要重新扫描
- READONLY 从节点也可以用于分担读压力（可选优化）

#### 5.1.4 地址输入格式说明

| 模式 | 地址格式 | 示例 |
|------|---------|------|
| 单机 | 单个 `host:port` | `127.0.0.1:6379` |
| 集群 | 多行 `host:port`（每行一个） | `192.168.1.101:7001`<br>`192.168.1.102:7002`<br>`192.168.1.103:7003` |
| 哨兵 | 多行 `host:port`（每行一个） | `192.168.1.101:26379`<br>`192.168.1.102:26379`<br>`192.168.1.103:26379` |

**集群模式说明：**
- Redis Cluster 使用独立的端口（通常从 7000 开始）
- 最少需要 3 个主节点 + 3 个从节点（6 个节点）
- 只需填写部分节点地址，客户端会通过 CLUSTER SLOTS 命令自动发现所有节点
- 不支持数据库切换（集群模式只使用 DB0）

**哨兵模式说明：**
- 哨兵默认端口为 26379
- 主节点名称（masterName）是哨兵监控的 Redis 主节点名称
- 建议填写所有哨兵节点地址以确保高可用
- 支持数据库切换（DB0-DB15）
- 如果哨兵有密码保护，需要单独填写哨兵密码

```typescript
  { name: 'APPEND', syntax: 'APPEND key value', descriptionKey: 'redis.commands.appendDesc' },

  // ... 更多命令（完整列表包含 100+ 命令）
];

/** 根据输入获取匹配的命令 */
export function matchCommands(input: string): RedisCommandInfo[] {
  const upperInput = input.toUpperCase().trim();
  if (!upperInput) return [];
  return REDIS_ALL_COMMANDS.filter(cmd => cmd.name.startsWith(upperInput));
}

/** 根据命令名获取命令信息 */
export function getCommandInfo(name: string): RedisCommandInfo | undefined {
  return REDIS_ALL_COMMANDS.find(cmd => cmd.name.toUpperCase() === name.toUpperCase());
}
```

### 6.3 组件架构
