## 注意事项

1. **Ollama API 端点**:
   - 默认: `http://localhost:11434`
   - 模型列表: `GET /api/tags`
   - 下载模型: `POST /api/pull`
   - 删除模型: `DELETE /api/delete`

2. **远程连接**:
   - 需要关联 SSH 连接
   - 通过 SSH 隧道访问远程 Ollama

3. **错误处理**:
   - 统一使用 `Result<T, String>` 返回
   - 前端显示友好的错误提示
