# Oracle 完整数据库支持设计文档

## 1. 概述

### 1.1 目标
为 ZWD-OpsBot 添加完整的 Oracle 数据库支持，实现与 MySQL 完全对等的所有功能，包括：
- 数据库连接管理
- Schema 树浏览
- 表管理（创建、编辑、删除、重命名）
- 表结构编辑（列、索引、外键、检查约束、触发器）
- 数据编辑和查询
- SQL 编辑器
- ER 图设计器

### 1.2 Oracle 与 MySQL 的关系
Oracle 是企业级关系型数据库，与 MySQL 有显著的架构和语法差异：

- **架构模型**: Oracle 使用 Schema（用户）组织对象，而非 MySQL 的 Database
- **标识符**: Oracle 使用双引号，MySQL 使用反引号
- **数据类型**: Oracle 使用 NUMBER、VARCHAR2 等独特类型
- **自增机制**: Oracle 使用 IDENTITY（12c+）或 SEQUENCE
- **注释语法**: Oracle 使用 COMMENT ON 语句
- **特有对象**: Package、Type、Synonym 等

### 1.3 支持的 Oracle 版本
- Oracle Database 11g (11.2+)
- Oracle Database 12c (12.1+) - 推荐
- Oracle Database 18c
- Oracle Database 19c (LTS)
- Oracle Database 21c
- Oracle Database 23c (Free)

## 3. Oracle 与 MySQL 主要差异

### 3.1 数据类型差异

| MySQL 类型 | Oracle 类型 | 说明 |
|-----------|-------------|------|
| INT | NUMBER(10) | Oracle 使用 NUMBER 统一处理整数 |
| BIGINT | NUMBER(19) | 大整数 |
| SMALLINT | NUMBER(5) | 小整数 |
| TINYINT | NUMBER(3) | 微整数 |
| DECIMAL(p,s) | NUMBER(p,s) | 精确小数 |
| FLOAT | BINARY_FLOAT | 单精度浮点 |
| DOUBLE | BINARY_DOUBLE | 双精度浮点 |
| VARCHAR(n) | VARCHAR2(n) | 可变长字符串 |
| CHAR(n) | CHAR(n) | 固定长度字符串 |
| TEXT | CLOB | 长文本 |
| LONGTEXT | CLOB | 超长文本 |
| BLOB | BLOB | 二进制大对象 |
| DATE | DATE | Oracle DATE 包含时间 |
| DATETIME | TIMESTAMP | 日期时间 |
| TIMESTAMP | TIMESTAMP | 时间戳 |
| TIME | INTERVAL DAY TO SECOND | 时间（或用 DATE） |
| BOOLEAN | NUMBER(1) | Oracle 无原生布尔，用 0/1 |
| JSON | JSON (21c+) / CLOB | JSON 数据 |
| UUID | RAW(16) | 通过 SYS_GUID() 生成 |

### 3.2 Oracle 特有类型

| 类型 | 说明 |
|------|------|
| NUMBER(p,s) | 通用数字类型，精度 1-38 |
| VARCHAR2(n) | 可变字符串，最大 4000/32767 字节 |
| NVARCHAR2(n) | Unicode 可变字符串 |
| NCHAR(n) | Unicode 固定字符串 |
| CLOB | 字符大对象，最大 4GB |
| NCLOB | Unicode 字符大对象 |
| BLOB | 二进制大对象 |
| BFILE | 外部文件指针 |
| RAW(n) | 原始二进制，最大 2000 字节 |
| LONG RAW | 长二进制（已废弃，用 BLOB） |
| ROWID | 行标识符 |
| UROWID | 通用行标识符 |
| XMLTYPE | XML 数据 |
| SDO_GEOMETRY | 空间数据 |
| INTERVAL YEAR TO MONTH | 年月间隔 |
| INTERVAL DAY TO SECOND | 日秒间隔 |
| TIMESTAMP WITH TIME ZONE | 带时区时间戳 |
| TIMESTAMP WITH LOCAL TIME ZONE | 本地时区时间戳 |

### 3.3 语法差异

#### 3.3.1 标识符引用
```sql
-- MySQL: 反引号
`table_name`

-- Oracle: 双引号
"table_name"
```

#### 3.3.2 自增主键
```sql
-- MySQL
id INT AUTO_INCREMENT PRIMARY KEY

-- Oracle 12c+ (IDENTITY)
id NUMBER GENERATED ALWAYS AS IDENTITY PRIMARY KEY

-- Oracle 11g 及以下 (SEQUENCE + TRIGGER)
CREATE SEQUENCE seq_table_id START WITH 1 INCREMENT BY 1;
CREATE TRIGGER trg_table_id BEFORE INSERT ON table_name
FOR EACH ROW BEGIN
  SELECT seq_table_id.NEXTVAL INTO :NEW.id FROM DUAL;
END;
```

#### 3.3.3 注释语法
```sql
-- MySQL: 内联注释
CREATE TABLE users (
  id INT COMMENT '用户ID'
) COMMENT='用户表';

-- Oracle: 单独的 COMMENT ON 语句
CREATE TABLE users (id NUMBER);
COMMENT ON TABLE users IS '用户表';
COMMENT ON COLUMN users.id IS '用户ID';
```

#### 3.3.4 字符串连接
```sql
-- MySQL
CONCAT(a, b, c)

-- Oracle
a || b || c
```

#### 3.3.5 分页
```sql
-- MySQL
SELECT * FROM table LIMIT 10 OFFSET 20;

-- Oracle 12c+
SELECT * FROM table OFFSET 20 ROWS FETCH NEXT 10 ROWS ONLY;

-- Oracle 11g 及以下
SELECT * FROM (
  SELECT t.*, ROWNUM rn FROM (
    SELECT * FROM table
  ) t WHERE ROWNUM <= 30
) WHERE rn > 20;
```

#### 3.3.6 布尔处理
```sql
-- MySQL
is_active BOOLEAN DEFAULT TRUE

-- Oracle (使用 NUMBER + CHECK)
is_active NUMBER(1) DEFAULT 1 CHECK (is_active IN (0, 1))
```

#### 3.3.7 空表查询
```sql
-- MySQL
SELECT 1;

-- Oracle
SELECT 1 FROM DUAL;
```

### 3.4 DDL 差异

#### 3.4.1 CREATE TABLE
```sql
-- Oracle 不支持 IF NOT EXISTS（需要 PL/SQL 或异常处理）
-- Oracle 不支持 ENGINE、CHARSET、COLLATE

CREATE TABLE "schema"."table_name" (
  "id" NUMBER GENERATED ALWAYS AS IDENTITY,
  "name" VARCHAR2(100) NOT NULL,
  "created_at" TIMESTAMP DEFAULT SYSTIMESTAMP,
  CONSTRAINT "pk_table" PRIMARY KEY ("id")
) TABLESPACE users;

COMMENT ON TABLE "schema"."table_name" IS '表注释';
COMMENT ON COLUMN "schema"."table_name"."name" IS '列注释';
```

#### 3.4.2 索引
```sql
-- 普通索引
CREATE INDEX "idx_name" ON "table"("column");

-- 唯一索引
CREATE UNIQUE INDEX "uk_name" ON "table"("column");

-- 位图索引（适合低基数列）
CREATE BITMAP INDEX "bmp_status" ON "table"("status");

-- 函数索引
CREATE INDEX "idx_upper_name" ON "table"(UPPER("name"));

-- 复合索引
CREATE INDEX "idx_composite" ON "table"("col1", "col2");
```

#### 3.4.3 外键
```sql
ALTER TABLE "child_table"
  ADD CONSTRAINT "fk_child_parent"
  FOREIGN KEY ("parent_id")
  REFERENCES "parent_table"("id")
  ON DELETE CASCADE;
-- 注意：Oracle 不支持 ON UPDATE CASCADE
```

#### 4.2.4 Oracle 特有查询

```sql
-- 获取 Schema 列表
SELECT username FROM all_users
WHERE username NOT IN ('SYS', 'SYSTEM', 'OUTLN', 'DIP', ...)
ORDER BY username;

-- 获取表列表
SELECT table_name, num_rows
FROM all_tables
WHERE owner = :schema
ORDER BY table_name;

-- 获取列信息
SELECT
    column_name,
    data_type,
    data_length,
    data_precision,
    data_scale,
    nullable,
    data_default,
    char_length
FROM all_tab_columns
WHERE owner = :schema AND table_name = :table
ORDER BY column_id;

-- 获取主键信息
SELECT cols.column_name
FROM all_constraints cons
JOIN all_cons_columns cols ON cons.constraint_name = cols.constraint_name
WHERE cons.owner = :schema
  AND cons.table_name = :table
  AND cons.constraint_type = 'P'
ORDER BY cols.position;

-- 获取索引信息
SELECT
    idx.index_name,
    idx.uniqueness,
    idx.index_type,
    cols.column_name,
    cols.column_position
FROM all_indexes idx
JOIN all_ind_columns cols ON idx.index_name = cols.index_name
WHERE idx.owner = :schema AND idx.table_name = :table
ORDER BY idx.index_name, cols.column_position;

-- 获取外键信息
SELECT
    cons.constraint_name,
    cols.column_name,
    r_cons.table_name AS ref_table,
    r_cols.column_name AS ref_column,
    cons.delete_rule
FROM all_constraints cons
JOIN all_cons_columns cols ON cons.constraint_name = cols.constraint_name
JOIN all_constraints r_cons ON cons.r_constraint_name = r_cons.constraint_name
JOIN all_cons_columns r_cols ON r_cons.constraint_name = r_cols.constraint_name
WHERE cons.owner = :schema
  AND cons.table_name = :table
  AND cons.constraint_type = 'R';

-- 获取检查约束
SELECT constraint_name, search_condition
FROM all_constraints
WHERE owner = :schema
  AND table_name = :table
  AND constraint_type = 'C'
  AND generated = 'USER NAME';

-- 获取触发器
SELECT
    trigger_name,
    triggering_event,
    trigger_type,
    trigger_body,
    status
FROM all_triggers
WHERE owner = :schema AND table_name = :table;

-- 获取表 DDL
SELECT DBMS_METADATA.GET_DDL('TABLE', :table, :schema) FROM DUAL;

-- 获取列注释
SELECT column_name, comments
FROM all_col_comments
WHERE owner = :schema AND table_name = :table;

-- 获取表注释
SELECT comments
FROM all_tab_comments
WHERE owner = :schema AND table_name = :table;

-- 获取序列
SELECT sequence_name, min_value, max_value, increment_by, last_number
FROM all_sequences
WHERE sequence_owner = :schema;

-- 获取 Package
SELECT object_name, object_type, status
FROM all_objects
WHERE owner = :schema AND object_type IN ('PACKAGE', 'PACKAGE BODY');

-- 获取同义词
SELECT synonym_name, table_owner, table_name
FROM all_synonyms
WHERE owner = :schema;
```

#### 4.3.4 SQL 生成器

```typescript
// front/utils/sql-generator/oracle.ts

import { DiagramData, TableNode, FieldNode, IndexNode, RelationshipNode } from '@/types/diagram'

export function toOracle(diagram: DiagramData): string {
  const statements: string[] = []
  const commentStatements: string[] = []
  const indexStatements: string[] = []
  const fkStatements: string[] = []

  // 生成表定义
  diagram.tables.forEach((table) => {
    const { tableSql, comments, indexes } = generateTableSQL(table, diagram)
    statements.push(tableSql)
    commentStatements.push(...comments)
    indexStatements.push(...indexes)
  })

  // 生成外键约束
  diagram.relationships.forEach((rel) => {
    const fk = generateForeignKey(rel, diagram)
    if (fk) fkStatements.push(fk)
  })

  return [
    '-- Tables',
    statements.join('\n\n'),
    '',
    '-- Comments',
    commentStatements.join('\n'),
    '',
    '-- Indexes',
    indexStatements.join('\n'),
    '',
    '-- Foreign Keys',
    fkStatements.join('\n'),
  ].join('\n')
}

function generateTableSQL(table: TableNode, diagram: DiagramData): {
  tableSql: string
  comments: string[]
  indexes: string[]
} {
  const columns: string[] = []
  const constraints: string[] = []
  const comments: string[] = []
  const indexes: string[] = []

  // 处理列
  table.fields.forEach((field) => {
    columns.push(generateColumnSQL(field))

    // 收集列注释
    if (field.comment) {
      comments.push(
        `COMMENT ON COLUMN "${table.name}"."${field.name}" IS '${escapeQuotes(field.comment)}';`
      )
    }
  })

  // 主键约束
  const pkFields = table.fields.filter((f) => f.primaryKey)
  if (pkFields.length > 0) {
    const pkCols = pkFields.map((f) => `"${f.name}"`).join(', ')
    constraints.push(`CONSTRAINT "pk_${table.name}" PRIMARY KEY (${pkCols})`)
  }

  // 表注释
  if (table.comment) {
    comments.push(
      `COMMENT ON TABLE "${table.name}" IS '${escapeQuotes(table.comment)}';`
    )
  }

  // 索引
  table.indexes?.forEach((idx) => {
    indexes.push(generateIndexSQL(table.name, idx))
  })

  // 组装 CREATE TABLE
  const allDefs = [...columns, ...constraints]
  let tableSql = `CREATE TABLE "${table.name}" (\n  ${allDefs.join(',\n  ')}\n)`

  // 表选项
  if (table.tablespace) {
    tableSql += ` TABLESPACE ${table.tablespace}`
  }

  tableSql += ';'

  return { tableSql, comments, indexes }
}

function generateColumnSQL(field: FieldNode): string {
  const parts: string[] = []

  // 列名
  parts.push(`"${field.name}"`)

  // 数据类型
  parts.push(formatDataType(field))

  // IDENTITY（自增）
  if (field.autoIncrement) {
    parts.push('GENERATED ALWAYS AS IDENTITY')
  }

  // 默认值
  if (field.defaultValue !== undefined && field.defaultValue !== '') {
    const defaultVal = formatDefault(field)
    parts.push(`DEFAULT ${defaultVal}`)
  }

  // NOT NULL
  if (!field.nullable && !field.primaryKey) {
    parts.push('NOT NULL')
  }

  // 唯一约束
  if (field.unique && !field.primaryKey) {
    parts.push('UNIQUE')
  }

  // CHECK 约束
  if (field.check) {
    parts.push(`CHECK (${field.check})`)
  }

  return parts.join(' ')
}

function formatDataType(field: FieldNode): string {
  const type = field.type.toUpperCase()

  switch (type) {
    case 'NUMBER':
      if (field.precision && field.scale !== undefined) {
        return `NUMBER(${field.precision}, ${field.scale})`
      } else if (field.precision) {
        return `NUMBER(${field.precision})`
      }
      return 'NUMBER'

    case 'VARCHAR2':
    case 'NVARCHAR2':
    case 'CHAR':
    case 'NCHAR':
    case 'RAW':
      return `${type}(${field.length || 255})`

    case 'TIMESTAMP':
    case 'TIMESTAMP WITH TIME ZONE':
    case 'TIMESTAMP WITH LOCAL TIME ZONE':
      if (field.precision !== undefined) {
        return `${type}(${field.precision})`
      }
      return type

    default:
      return type
  }
}

function formatDefault(field: FieldNode): string {
  const value = field.defaultValue
  const type = field.type.toUpperCase()

  // 系统函数不需要引号
  const systemFunctions = ['SYSDATE', 'SYSTIMESTAMP', 'SYS_GUID()', 'USER', 'NULL']
  if (systemFunctions.includes(value.toUpperCase())) {
    return value.toUpperCase()
  }

  // 数值类型不需要引号
  if (['NUMBER', 'BINARY_FLOAT', 'BINARY_DOUBLE'].includes(type)) {
    return value
  }

  // 字符类型需要引号
  return `'${escapeQuotes(value)}'`
}

function generateIndexSQL(tableName: string, index: IndexNode): string {
  const indexType = index.type === 'BITMAP' ? 'BITMAP ' : ''
  const unique = index.unique && index.type !== 'BITMAP' ? 'UNIQUE ' : ''
  const columns = index.columns.map((c) => `"${c}"`).join(', ')

  return `CREATE ${unique}${indexType}INDEX "${index.name}" ON "${tableName}" (${columns});`
}

function generateForeignKey(rel: RelationshipNode, diagram: DiagramData): string | null {
  const sourceTable = diagram.tables.find((t) => t.id === rel.sourceTableId)
  const targetTable = diagram.tables.find((t) => t.id === rel.targetTableId)

  if (!sourceTable || !targetTable) return null

  const sourceField = sourceTable.fields.find((f) => f.id === rel.sourceFieldId)
  const targetField = targetTable.fields.find((f) => f.id === rel.targetFieldId)

  if (!sourceField || !targetField) return null

  let sql = `ALTER TABLE "${sourceTable.name}" ADD CONSTRAINT "${rel.name || `fk_${sourceTable.name}_${targetTable.name}`}"`
  sql += ` FOREIGN KEY ("${sourceField.name}")`
  sql += ` REFERENCES "${targetTable.name}" ("${targetField.name}")`

  // Oracle 不支持 ON UPDATE，只支持 ON DELETE
  if (rel.onDelete && rel.onDelete !== 'NO ACTION') {
    sql += ` ON DELETE ${rel.onDelete}`
  }

  sql += ';'
  return sql
}

function escapeQuotes(str: string): string {
  return str.replace(/'/g, "''")
}
```

## 8. 限制说明

1. **ON UPDATE CASCADE**: Oracle 外键不支持 ON UPDATE CASCADE，生成器会忽略
2. **IF NOT EXISTS**: Oracle 不支持 IF NOT EXISTS，需要通过异常处理实现
3. **自增列限制**: 一个表只能有一个 IDENTITY 列
4. **VARCHAR2 长度**: 默认最大 4000 字节，12c+ 可扩展到 32767
5. **OCI 依赖**: 使用 oracle crate 需要安装 Oracle Instant Client
6. **空表查询**: 需要使用 FROM DUAL
