# 达梦数据库（DM）完整支持设计文档

## 1. 概述

### 1.1 目标
为 ZWD-OpsBot 添加完整的达梦数据库（DM Database）支持，实现与 MySQL 完全对等的所有功能，包括：
- 数据库连接管理
- Schema 树浏览
- 表管理（创建、编辑、删除、重命名）
- 表结构编辑（列、索引、外键、检查约束、触发器）
- 数据编辑和查询
- SQL 编辑器
- ER 图设计器

### 1.2 达梦数据库简介
达梦数据库（DM Database）是武汉达梦数据库股份有限公司自主研发的新一代大型通用关系型数据库管理系统，是国产数据库领军产品，广泛应用于政府、金融、电信等关键领域。

#### 核心特点
- **高度兼容 Oracle**：语法、数据类型、存储过程等与 Oracle 高度兼容
- **国产自主可控**：符合国产化信创要求
- **企业级特性**：支持集群、高可用、读写分离
- **多平台支持**：Windows、Linux、国产操作系统（麒麟、统信等）

### 1.3 达梦与 Oracle/MySQL 的关系
达梦在设计上高度兼容 Oracle，但也有自己的特色：

| 特性 | 达梦 | Oracle | MySQL |
|-----|------|--------|-------|
| **架构模型** | Schema（模式） | Schema（用户） | Database |
| **标识符引用** | 双引号 `"name"` | 双引号 `"name"` | 反引号 `` `name` `` |
| **自增机制** | IDENTITY | IDENTITY/SEQUENCE | AUTO_INCREMENT |
| **分页语法** | LIMIT/OFFSET 或 ROWNUM | FETCH FIRST/ROWNUM | LIMIT/OFFSET |
| **字符串连接** | `\|\|` 或 CONCAT | `\|\|` | CONCAT |
| **默认端口** | 5236 | 1521 | 3306 |

### 1.4 支持的达梦版本
- DM7 (7.x)
- DM8 (8.x) - 推荐，当前主流版本

## 3. 达梦与 MySQL/Oracle 主要差异

### 3.1 数据类型对照

| MySQL 类型 | 达梦类型 | 说明 |
|-----------|---------|------|
| INT | INT / INTEGER | 4 字节整数 |
| BIGINT | BIGINT | 8 字节大整数 |
| SMALLINT | SMALLINT | 2 字节小整数 |
| TINYINT | TINYINT | 1 字节微整数 |
| DECIMAL(p,s) | DECIMAL(p,s) / NUMBER(p,s) | 精确小数 |
| FLOAT | FLOAT / REAL | 单精度浮点 |
| DOUBLE | DOUBLE / DOUBLE PRECISION | 双精度浮点 |
| VARCHAR(n) | VARCHAR(n) / VARCHAR2(n) | 可变长字符串 |
| CHAR(n) | CHAR(n) | 固定长度字符串 |
| TEXT | TEXT / CLOB | 长文本 |
| LONGTEXT | CLOB | 超长文本 |
| BLOB | BLOB | 二进制大对象 |
| DATE | DATE | 日期 |
| DATETIME | DATETIME / TIMESTAMP | 日期时间 |
| TIMESTAMP | TIMESTAMP | 时间戳 |
| TIME | TIME | 时间 |
| BOOLEAN | BIT / BOOLEAN | 布尔值 |
| JSON | TEXT（存储 JSON） | JSON 数据 |

### 3.2 达梦特有数据类型

| 类型 | 说明 |
|------|------|
| NUMBER(p,s) | 通用数字类型（兼容 Oracle） |
| VARCHAR2(n) | 可变字符串（兼容 Oracle） |
| NVARCHAR(n) | Unicode 可变字符串 |
| NCHAR(n) | Unicode 固定字符串 |
| CLOB | 字符大对象 |
| BLOB | 二进制大对象 |
| BFILE | 外部文件指针 |
| ROWID | 行标识符 |
| INTERVAL YEAR TO MONTH | 年月间隔 |
| INTERVAL DAY TO SECOND | 日秒间隔 |
| TIMESTAMP WITH TIME ZONE | 带时区时间戳 |

### 3.3 语法差异

#### 3.3.1 标识符引用
```sql
-- MySQL: 反引号
`table_name`

-- 达梦: 双引号（默认大小写敏感时需要）
"table_name"
```

#### 3.3.2 自增主键
```sql
-- MySQL
id INT AUTO_INCREMENT PRIMARY KEY

-- 达梦 (IDENTITY)
id INT IDENTITY(1, 1) PRIMARY KEY
-- 或
id INT GENERATED ALWAYS AS IDENTITY PRIMARY KEY
```

#### 3.3.3 注释语法
```sql
-- MySQL: 内联注释
CREATE TABLE users (
  id INT COMMENT '用户ID'
) COMMENT='用户表';

-- 达梦: 支持内联注释和 COMMENT ON 语句
CREATE TABLE users (id INT);
COMMENT ON TABLE users IS '用户表';
COMMENT ON COLUMN users.id IS '用户ID';
```

#### 3.3.4 分页
```sql
-- MySQL
SELECT * FROM table LIMIT 10 OFFSET 20;

-- 达梦（兼容 MySQL 语法）
SELECT * FROM table LIMIT 20, 10;
-- 或
SELECT * FROM table LIMIT 10 OFFSET 20;

-- 达梦（使用 ROWNUM，兼容 Oracle）
SELECT * FROM (
  SELECT t.*, ROWNUM rn FROM (
    SELECT * FROM table
  ) t WHERE ROWNUM <= 30
) WHERE rn > 20;
```

#### 3.3.5 字符串连接
```sql
-- MySQL
CONCAT(a, b, c)

-- 达梦（两种方式都支持）
a || b || c
CONCAT(a, b, c)
```

#### 3.3.6 空表查询
```sql
-- MySQL
SELECT 1;

-- 达梦
SELECT 1 FROM DUAL;
-- 或直接
SELECT 1;
```

### 3.4 DDL 差异

#### 3.4.1 CREATE TABLE
```sql
CREATE TABLE "SCHEMA_NAME"."TABLE_NAME" (
  "ID" INT IDENTITY(1, 1) PRIMARY KEY,
  "NAME" VARCHAR(100) NOT NULL,
  "CREATED_AT" TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  "STATUS" INT DEFAULT 1 CHECK ("STATUS" IN (0, 1))
) TABLESPACE "MAIN";

COMMENT ON TABLE "SCHEMA_NAME"."TABLE_NAME" IS '表注释';
COMMENT ON COLUMN "SCHEMA_NAME"."TABLE_NAME"."NAME" IS '列注释';
```

#### 3.4.2 索引
```sql
-- 普通索引
CREATE INDEX "IDX_NAME" ON "TABLE"("COLUMN");

-- 唯一索引
CREATE UNIQUE INDEX "UK_NAME" ON "TABLE"("COLUMN");

-- 复合索引
CREATE INDEX "IDX_COMPOSITE" ON "TABLE"("COL1", "COL2");

-- 函数索引
CREATE INDEX "IDX_UPPER_NAME" ON "TABLE"(UPPER("NAME"));
```

#### 3.4.3 外键
```sql
ALTER TABLE "CHILD_TABLE"
  ADD CONSTRAINT "FK_CHILD_PARENT"
  FOREIGN KEY ("PARENT_ID")
  REFERENCES "PARENT_TABLE"("ID")
  ON DELETE CASCADE
  ON UPDATE CASCADE;
```

#### 4.2.1 依赖选择

达梦数据库提供 ODBC 接口，可以使用 Rust 的 ODBC 绑定：

```toml
# Cargo.toml
[dependencies]
# 方案1: 使用 ODBC（推荐，达梦官方支持）

# 方案2: 使用通用数据库连接（如果达梦提供 Rust SDK）
```

**推荐使用 ODBC 方式**，因为：
1. 达梦官方提供 ODBC 驱动
2. 跨平台兼容性好
3. 接口稳定成熟

```rust
/// 达梦数据库驱动

    conn: Arc<Mutex<Connection<'static>>>,
    env: Arc<Environment>,

impl DmDriver {
    /// 创建达梦数据库连接
    pub async fn connect(
        host: &str,
        port: u16,
        username: &str,
        password: &str,
        database: &str,
    ) -> Result<Self, String> {
        // ODBC 连接字符串
        let conn_string = format!(
            "DRIVER={{DM8 ODBC DRIVER}};SERVER={};PORT={};DATABASE={};UID={};PWD={}",
            host, port, database, username, password
        );

        let env = Environment::new().map_err(|e| e.to_string())?;
        let conn = env.connect_with_connection_string(
            &conn_string,
            ConnectionOptions::default()
        ).map_err(|e| e.to_string())?;

        log::info!("Connected to DM Database: {}:{}/{}", host, port, database);

        Ok(Self {
            conn: Arc::new(Mutex::new(conn)),
            env: Arc::new(env),
        })
    }
```

#### 4.2.3 达梦特有查询

```sql
-- 获取 Schema 列表（排除系统用户）
SELECT USERNAME FROM ALL_USERS
WHERE USERNAME NOT IN ('SYS', 'SYSTEM', 'CTISYS', 'SYSAUDITOR', 'SYSSSO', 'SYSDBA')
ORDER BY USERNAME;

-- 获取表列表
SELECT TABLE_NAME, NUM_ROWS
FROM ALL_TABLES
WHERE OWNER = :schema
ORDER BY TABLE_NAME;

-- 获取列信息
SELECT
    COLUMN_NAME,
    DATA_TYPE,
    DATA_LENGTH,
    DATA_PRECISION,
    DATA_SCALE,
    NULLABLE,
    DATA_DEFAULT,
    CHAR_LENGTH
FROM ALL_TAB_COLUMNS
WHERE OWNER = :schema AND TABLE_NAME = :table
ORDER BY COLUMN_ID;

-- 获取主键信息
SELECT COLS.COLUMN_NAME
FROM ALL_CONSTRAINTS CONS
JOIN ALL_CONS_COLUMNS COLS ON CONS.CONSTRAINT_NAME = COLS.CONSTRAINT_NAME
WHERE CONS.OWNER = :schema
  AND CONS.TABLE_NAME = :table
  AND CONS.CONSTRAINT_TYPE = 'P'
ORDER BY COLS.POSITION;

-- 获取索引信息
SELECT
    IDX.INDEX_NAME,
    IDX.UNIQUENESS,
    IDX.INDEX_TYPE,
    COLS.COLUMN_NAME,
    COLS.COLUMN_POSITION
FROM ALL_INDEXES IDX
JOIN ALL_IND_COLUMNS COLS ON IDX.INDEX_NAME = COLS.INDEX_NAME AND IDX.OWNER = COLS.INDEX_OWNER
WHERE IDX.OWNER = :schema AND IDX.TABLE_NAME = :table
ORDER BY IDX.INDEX_NAME, COLS.COLUMN_POSITION;

-- 获取外键信息
SELECT
    CONS.CONSTRAINT_NAME,
    COLS.COLUMN_NAME,
    R_CONS.TABLE_NAME AS REF_TABLE,
    R_COLS.COLUMN_NAME AS REF_COLUMN,
    CONS.DELETE_RULE
FROM ALL_CONSTRAINTS CONS
JOIN ALL_CONS_COLUMNS COLS ON CONS.CONSTRAINT_NAME = COLS.CONSTRAINT_NAME
JOIN ALL_CONSTRAINTS R_CONS ON CONS.R_CONSTRAINT_NAME = R_CONS.CONSTRAINT_NAME
JOIN ALL_CONS_COLUMNS R_COLS ON R_CONS.CONSTRAINT_NAME = R_COLS.CONSTRAINT_NAME
WHERE CONS.OWNER = :schema
  AND CONS.TABLE_NAME = :table
  AND CONS.CONSTRAINT_TYPE = 'R';

-- 获取检查约束
SELECT CONSTRAINT_NAME, SEARCH_CONDITION
FROM ALL_CONSTRAINTS
WHERE OWNER = :schema
  AND TABLE_NAME = :table
  AND CONSTRAINT_TYPE = 'C';

-- 获取触发器
SELECT
    TRIGGER_NAME,
    TRIGGERING_EVENT,
    TRIGGER_TYPE,
    TRIGGER_BODY,
    STATUS
FROM ALL_TRIGGERS
WHERE OWNER = :schema AND TABLE_NAME = :table;

-- 获取表 DDL
SELECT DBMS_METADATA.GET_DDL('TABLE', :table, :schema) FROM DUAL;

-- 获取列注释
SELECT COLUMN_NAME, COMMENTS
FROM ALL_COL_COMMENTS
WHERE OWNER = :schema AND TABLE_NAME = :table;

-- 获取表注释
SELECT COMMENTS
FROM ALL_TAB_COMMENTS
WHERE OWNER = :schema AND TABLE_NAME = :table;

-- 获取序列
SELECT SEQUENCE_NAME, MIN_VALUE, MAX_VALUE, INCREMENT_BY, LAST_NUMBER
FROM ALL_SEQUENCES
WHERE SEQUENCE_OWNER = :schema;

-- 获取同义词
SELECT SYNONYM_NAME, TABLE_OWNER, TABLE_NAME
FROM ALL_SYNONYMS
WHERE OWNER = :schema;
```

#### 4.3.4 SQL 生成器

```typescript
// front/utils/sql-generator/dm.ts

import { DiagramData, TableNode, FieldNode, IndexNode, RelationshipNode } from '@/types/diagram'

export function toDm(diagram: DiagramData): string {
  const statements: string[] = []
  const commentStatements: string[] = []
  const indexStatements: string[] = []
  const fkStatements: string[] = []

  // 生成表定义
  diagram.tables.forEach((table) => {
    const { tableSql, comments, indexes } = generateTableSQL(table, diagram)
    statements.push(tableSql)
    commentStatements.push(...comments)
    indexStatements.push(...indexes)
  })

  // 生成外键约束
  diagram.relationships.forEach((rel) => {
    const fk = generateForeignKey(rel, diagram)
    if (fk) fkStatements.push(fk)
  })

  return [
    '-- 达梦数据库 DDL',
    '-- Tables',
    statements.join('\n\n'),
    '',
    '-- Comments',
    commentStatements.join('\n'),
    '',
    '-- Indexes',
    indexStatements.join('\n'),
    '',
    '-- Foreign Keys',
    fkStatements.join('\n'),
  ].join('\n')
}

function generateTableSQL(table: TableNode, diagram: DiagramData): {
  tableSql: string
  comments: string[]
  indexes: string[]
} {
  const columns: string[] = []
  const constraints: string[] = []
  const comments: string[] = []
  const indexes: string[] = []

  // 处理列
  table.fields.forEach((field) => {
    columns.push(generateColumnSQL(field))

    // 收集列注释
    if (field.comment) {
      comments.push(
        `COMMENT ON COLUMN "${table.name}"."${field.name}" IS '${escapeQuotes(field.comment)}';`
      )
    }
  })

  // 主键约束
  const pkFields = table.fields.filter((f) => f.primaryKey)
  if (pkFields.length > 0) {
    const pkCols = pkFields.map((f) => `"${f.name}"`).join(', ')
    constraints.push(`CONSTRAINT "PK_${table.name.toUpperCase()}" PRIMARY KEY (${pkCols})`)
  }

  // 表注释
  if (table.comment) {
    comments.push(
      `COMMENT ON TABLE "${table.name}" IS '${escapeQuotes(table.comment)}';`
    )
  }

  // 索引
  table.indexes?.forEach((idx) => {
    indexes.push(generateIndexSQL(table.name, idx))
  })

  // 组装 CREATE TABLE
  const allDefs = [...columns, ...constraints]
  let tableSql = `CREATE TABLE "${table.name}" (\n  ${allDefs.join(',\n  ')}\n)`

  // 表选项
  if (table.tablespace) {
    tableSql += ` TABLESPACE "${table.tablespace}"`
  }

  tableSql += ';'

  return { tableSql, comments, indexes }
}

function generateColumnSQL(field: FieldNode): string {
  const parts: string[] = []

  // 列名
  parts.push(`"${field.name}"`)

  // 数据类型
  parts.push(formatDataType(field))

  // IDENTITY（自增）
  if (field.autoIncrement) {
    parts.push('IDENTITY(1, 1)')
  }

  // 默认值
  if (field.defaultValue !== undefined && field.defaultValue !== '' && !field.autoIncrement) {
    const defaultVal = formatDefault(field)
    parts.push(`DEFAULT ${defaultVal}`)
  }

  // NOT NULL
  if (!field.nullable && !field.primaryKey) {
    parts.push('NOT NULL')
  }

  // 唯一约束
  if (field.unique && !field.primaryKey) {
    parts.push('UNIQUE')
  }

  // CHECK 约束
  if (field.check) {
    parts.push(`CHECK (${field.check})`)
  }

  return parts.join(' ')
}

function formatDataType(field: FieldNode): string {
  const type = field.type.toUpperCase()

  switch (type) {
    case 'DECIMAL':
    case 'NUMBER':
    case 'NUMERIC':
      if (field.precision && field.scale !== undefined) {
        return `${type}(${field.precision}, ${field.scale})`
      } else if (field.precision) {
        return `${type}(${field.precision})`
      }
      return type

    case 'VARCHAR':
    case 'VARCHAR2':
    case 'NVARCHAR':
    case 'CHAR':
    case 'NCHAR':
    case 'BINARY':
    case 'VARBINARY':
      return `${type}(${field.length || 255})`

    case 'TIME':
    case 'DATETIME':
    case 'TIMESTAMP':
    case 'TIMESTAMP WITH TIME ZONE':
      if (field.precision !== undefined && field.precision > 0) {
        return `${type}(${field.precision})`
      }
      return type

    default:
      return type
  }
}

function formatDefault(field: FieldNode): string {
  const value = field.defaultValue
  const type = field.type.toUpperCase()

  // 系统函数不需要引号
  const systemFunctions = [
    'CURRENT_TIMESTAMP', 'CURRENT_DATE', 'CURRENT_TIME',
    'SYSDATE', 'SYSTIMESTAMP', 'SYS_GUID()',
    'CURRENT_USER', 'USER', 'NULL'
  ]
  if (systemFunctions.includes(value.toUpperCase())) {
    return value.toUpperCase()
  }

  // 数值类型不需要引号
  const numericTypes = [
    'TINYINT', 'SMALLINT', 'INT', 'INTEGER', 'BIGINT',
    'FLOAT', 'DOUBLE', 'REAL', 'DECIMAL', 'NUMBER', 'NUMERIC'
  ]
  if (numericTypes.includes(type)) {
    return value
  }

  // 布尔类型
  if (type === 'BIT' || type === 'BOOLEAN') {
    return value.toLowerCase() === 'true' ? '1' : '0'
  }

  // 字符类型需要引号
  return `'${escapeQuotes(value)}'`
}

function generateIndexSQL(tableName: string, index: IndexNode): string {
  const unique = index.unique ? 'UNIQUE ' : ''
  const columns = index.columns.map((c) => `"${c}"`).join(', ')

  return `CREATE ${unique}INDEX "${index.name}" ON "${tableName}" (${columns});`
}

function generateForeignKey(rel: RelationshipNode, diagram: DiagramData): string | null {
  const sourceTable = diagram.tables.find((t) => t.id === rel.sourceTableId)
  const targetTable = diagram.tables.find((t) => t.id === rel.targetTableId)

  if (!sourceTable || !targetTable) return null

  const sourceField = sourceTable.fields.find((f) => f.id === rel.sourceFieldId)
  const targetField = targetTable.fields.find((f) => f.id === rel.targetFieldId)

  if (!sourceField || !targetField) return null

  let sql = `ALTER TABLE "${sourceTable.name}" ADD CONSTRAINT "${rel.name || `FK_${sourceTable.name}_${targetTable.name}`}"`
  sql += ` FOREIGN KEY ("${sourceField.name}")`
  sql += ` REFERENCES "${targetTable.name}" ("${targetField.name}")`

  // 达梦支持 ON DELETE 和 ON UPDATE
  if (rel.onDelete && rel.onDelete !== 'NO ACTION') {
    sql += ` ON DELETE ${rel.onDelete}`
  }
  if (rel.onUpdate && rel.onUpdate !== 'NO ACTION') {
    sql += ` ON UPDATE ${rel.onUpdate}`
  }

  sql += ';'
  return sql
}

function escapeQuotes(str: string): string {
  return str.replace(/'/g, "''")
}
```

### 4.5 ODBC 驱动安装

使用达梦 ODBC 驱动需要安装达梦客户端：

1. **Windows**:
   - 下载达梦客户端安装包
   - 安装后会自动注册 ODBC 驱动
   - 驱动名称：`DM8 ODBC DRIVER`

2. **Linux**:
   ```bash
   # 安装 unixODBC
   apt-get install unixodbc unixodbc-dev  # Debian/Ubuntu
   yum install unixODBC unixODBC-devel    # CentOS/RHEL

   # 配置达梦 ODBC 驱动
   # /etc/odbcinst.ini
   [DM8 ODBC DRIVER]
   Description = DM8 ODBC Driver
   Driver = /path/to/dm8/drivers/odbc/libdodbc.so
   ```

3. **macOS**:
   ```bash
   brew install unixodbc
   # 配置类似 Linux
   ```

### 12.4 待解决问题

#### 问题：达梦 ODBC 驱动未安装

**现象**：
```
Can't open lib 'DM8 ODBC DRIVER' : file not found
```

**原因**：
- 后端使用 ODBC 协议连接达梦
- unixODBC 已安装 ✅
- 达梦官方 ODBC 驱动（`libdmodbc.dylib`/`libdmodbc.so`）未安装 ❌

**解决方案**：
1. 从达梦服务器拷贝 ODBC 驱动文件
2. 或从达梦官网下载安装包提取驱动
3. 配置 `/etc/odbcinst.ini` 或 `~/.odbcinst.ini`

**驱动配置示例**：
```ini
[DM8 ODBC DRIVER]
Description = DM8 ODBC Driver
Driver = /path/to/libdmodbc.dylib
```
