# Elasticsearch 搜索引擎管理功能设计文档

## 1. 概述

### 1.1 目标
为 ZWD-OpsBot 添加 Elasticsearch 搜索引擎管理支持，作为中间件模块的搜索引擎实现。设计时需考虑：
- **复用现有架构**：使用已定义的 `MiddlewareConnection` 和 `elasticsearchConfig` 类型
- **策略模式解耦**：便于后续扩展 OpenSearch、Solr 等搜索引擎
- **遵循开发规范**：函数不超过80行，单文件不超过800行
- **版本兼容**：支持 ES 7.x/8.x 主流版本

### 1.2 核心功能

| 功能模块 | 说明 |
|---------|------|
| 连接管理 | 支持单节点/集群、多种认证方式、SSL/TLS |
| 集群监控 | 健康状态、节点信息、分片分配、集群设置 |
| 索引管理 | 列表、创建、删除、打开/关闭、映射、设置 |
| 文档操作 | 获取、创建、更新、删除、批量操作 |
| 查询分析 | DSL 查询、SQL 查询（ES 6.3+） |

### 1.3 与现有架构的集成点

| 集成点 | 现有实现 | Elasticsearch 集成方式 |
|-------|---------|----------------------|
| 连接类型 | `MiddlewareConnection` | 添加 `elasticsearchConfig` 配置 |
| 连接树 | `ConnectionTree.tsx` | 在中间件节点下显示 ES 子树 |
| 状态管理 | `connectionStore.ts` | 扩展中间件相关状态 |
| 服务层 | `services/middleware/` | 添加 ES 驱动实现 |

### 1.4 类型定义扩展（front/types/connection.ts）

```typescript
export interface MiddlewareConnection extends ConnectionBase {
  moduleType: ModuleType.Middleware

      ca?: string                      // CA 证书路径
    }
    requestTimeout?: number            // 请求超时 (毫秒)
  }
}
```

### 3.2 Elasticsearch Driver 实现

```rust
// backend/src/services/middleware/elasticsearch/driver.rs

use elasticsearch::{
    Elasticsearch,
    http::transport::{Transport, SingleNodeConnectionPool, TransportBuilder},
    auth::Credentials,
    cert::CertificateValidation,
};
use url::Url;
use std::sync::Arc;
use crate::services::middleware::traits::*;

pub struct ElasticsearchDriver {
    client: Elasticsearch,
    config: EsConfig,
}

impl ElasticsearchDriver {
    pub async fn connect(config: EsConfig) -> Result<Self, String> {
        let transport = Self::build_transport(&config)?;
        let client = Elasticsearch::new(transport);

        // 验证连接
        let driver = Self { client, config };
        driver.test_connection().await?;

        Ok(driver)
    }

    fn build_transport(config: &EsConfig) -> Result<Transport, String> {
        let url = Url::parse(&config.nodes[0])
            .map_err(|e| format!("Invalid URL: {}", e))?;

        let conn_pool = SingleNodeConnectionPool::new(url);
        let mut builder = TransportBuilder::new(conn_pool);

        // 配置认证
        match &config.auth_type {
            AuthType::Basic { username, password } => {
                builder = builder.auth(Credentials::Basic(
                    username.clone(),
                    password.clone(),
                ));
            }
            AuthType::ApiKey { api_key } => {
                builder = builder.auth(Credentials::ApiKey(
                    api_key.clone(),
                ));
            }
            AuthType::None => {}
        }

        // 配置 TLS
        if let Some(tls) = &config.tls {
            if !tls.verify_certificate {
                builder = builder.cert_validation(CertificateValidation::None);
            }
        }

        // 配置超时
        if let Some(timeout) = config.request_timeout {
            builder = builder.timeout(std::time::Duration::from_millis(timeout));
        }

        builder.build()
            .map_err(|e| format!("Failed to build transport: {}", e))
    }
}

#[async_trait::async_trait]
impl SearchEngineDriver for ElasticsearchDriver {
    async fn test_connection(&self) -> Result<EsConnectionInfo, String> {
        let response = self.client.info()
            .send()
            .await
            .map_err(|e| format!("Connection failed: {}", e))?;

        let info = response.json::<serde_json::Value>().await
            .map_err(|e| format!("Failed to parse response: {}", e))?;

        Ok(EsConnectionInfo {
            cluster_name: info["cluster_name"].as_str().unwrap_or("").to_string(),
            cluster_uuid: info["cluster_uuid"].as_str().unwrap_or("").to_string(),
            version: info["version"]["number"].as_str().unwrap_or("").to_string(),
        })
    }

    async fn disconnect(&self) -> Result<(), String> {
        // elasticsearch-rs 会在 drop 时自动清理
        Ok(())
    }

    async fn get_cluster_health(&self) -> Result<EsClusterHealth, String> {
        let response = self.client
            .cluster()
            .health(elasticsearch::cluster::ClusterHealthParts::None)
            .send()
            .await
            .map_err(|e| format!("Failed to get cluster health: {}", e))?;

        let json = response.json::<serde_json::Value>().await
            .map_err(|e| format!("Failed to parse response: {}", e))?;

        Ok(EsClusterHealth {
            cluster_name: json["cluster_name"].as_str().unwrap_or("").to_string(),
            status: json["status"].as_str().unwrap_or("unknown").to_string(),
            number_of_nodes: json["number_of_nodes"].as_i64().unwrap_or(0) as i32,
            number_of_data_nodes: json["number_of_data_nodes"].as_i64().unwrap_or(0) as i32,
            active_primary_shards: json["active_primary_shards"].as_i64().unwrap_or(0) as i32,
            active_shards: json["active_shards"].as_i64().unwrap_or(0) as i32,
            relocating_shards: json["relocating_shards"].as_i64().unwrap_or(0) as i32,
            initializing_shards: json["initializing_shards"].as_i64().unwrap_or(0) as i32,
            unassigned_shards: json["unassigned_shards"].as_i64().unwrap_or(0) as i32,
        })
    }

    async fn get_indices(&self, pattern: Option<&str>) -> Result<Vec<EsIndexSummary>, String> {
        let index_pattern = pattern.unwrap_or("*");
        let response = self.client
            .cat()
            .indices(elasticsearch::cat::CatIndicesParts::Index(&[index_pattern]))
            .format("json")
            .send()
            .await
            .map_err(|e| format!("Failed to get indices: {}", e))?;

        let indices: Vec<serde_json::Value> = response.json().await
            .map_err(|e| format!("Failed to parse response: {}", e))?;

        Ok(indices.iter().map(|idx| EsIndexSummary {
            name: idx["index"].as_str().unwrap_or("").to_string(),
            health: idx["health"].as_str().unwrap_or("").to_string(),
            status: idx["status"].as_str().unwrap_or("").to_string(),
            uuid: idx["uuid"].as_str().unwrap_or("").to_string(),
            docs_count: idx["docs.count"].as_str()
                .and_then(|s| s.parse().ok()).unwrap_or(0),
            docs_deleted: idx["docs.deleted"].as_str()
                .and_then(|s| s.parse().ok()).unwrap_or(0),
            store_size: idx["store.size"].as_str().unwrap_or("0b").to_string(),
            primary_shards: idx["pri"].as_str()
                .and_then(|s| s.parse().ok()).unwrap_or(0),
            replica_shards: idx["rep"].as_str()
                .and_then(|s| s.parse().ok()).unwrap_or(0),
        }).collect())
    }

    async fn create_index(&self, request: EsCreateIndexRequest) -> Result<(), String> {
        let mut body = serde_json::json!({});

        if let Some(settings) = request.settings {
            body["settings"] = settings;
        }
        if let Some(mappings) = request.mappings {
            body["mappings"] = mappings;
        }

        self.client
            .indices()
            .create(elasticsearch::indices::IndicesCreateParts::Index(&request.name))
            .body(body)
            .send()
            .await
            .map_err(|e| format!("Failed to create index: {}", e))?;

        Ok(())
    }

    async fn delete_index(&self, index: &str) -> Result<(), String> {
        self.client
            .indices()
            .delete(elasticsearch::indices::IndicesDeleteParts::Index(&[index]))
            .send()
            .await
            .map_err(|e| format!("Failed to delete index: {}", e))?;

        Ok(())
    }

    async fn search(&self, request: EsSearchRequest) -> Result<EsSearchResponse, String> {
        let response = self.client
            .search(elasticsearch::SearchParts::Index(&[&request.index]))
            .body(request.query)
            .from(request.from.unwrap_or(0) as i64)
            .size(request.size.unwrap_or(10) as i64)
            .send()
            .await
            .map_err(|e| format!("Search failed: {}", e))?;

        let json: serde_json::Value = response.json().await
            .map_err(|e| format!("Failed to parse response: {}", e))?;

        let hits = json["hits"]["hits"].as_array()
            .map(|arr| arr.iter().map(|hit| EsSearchHit {
                index: hit["_index"].as_str().unwrap_or("").to_string(),
                id: hit["_id"].as_str().unwrap_or("").to_string(),
                score: hit["_score"].as_f64(),
                source: hit["_source"].clone(),
            }).collect())
            .unwrap_or_default();

        Ok(EsSearchResponse {
            took: json["took"].as_i64().unwrap_or(0),
            timed_out: json["timed_out"].as_bool().unwrap_or(false),
            total: json["hits"]["total"]["value"].as_i64()
                .or_else(|| json["hits"]["total"].as_i64())
                .unwrap_or(0),
            max_score: json["hits"]["max_score"].as_f64(),
            hits,
        })
    }

    // ... 其他方法实现类似
}
```
