# Kafka 消息队列管理功能设计文档

## 1. 概述

### 1.1 目标
为 ZWD-OpsBot 添加 Apache Kafka 消息队列管理支持，作为中间件模块的首个消息队列实现。设计时需考虑：
- **复用现有架构**：使用已定义的 `MiddlewareConnection` 和 `kafkaConfig` 类型
- **策略模式解耦**：便于后续扩展 RabbitMQ、RocketMQ、Pulsar 等消息队列
- **遵循开发规范**：函数不超过80行，单文件不超过800行

### 1.2 与现有架构的集成点

| 集成点 | 现有实现 | Kafka 集成方式 |
|-------|---------|---------------|
| 连接类型 | `MiddlewareConnection.kafkaConfig` | 复用已有类型定义 |
| 连接树 | `ConnectionTree.tsx` | 在中间件节点下显示 Kafka 子树 |
| 状态管理 | `connectionStore.ts` | 扩展中间件相关状态 |
| 服务层 | `services/database/` 策略模式 | 创建 `services/middleware/` 相同模式 |

### 1.3 现有类型定义（front/types/connection.ts）

```rust
    async fn disconnect(&self) -> Result<(), String>;

    // ============ 集群信息 ============
    async fn get_cluster_info(&self) -> Result<ClusterInfo, String>;
    async fn get_brokers(&self) -> Result<Vec<BrokerInfo>, String>;

    // ============ Topic/Queue 操作 ============
    async fn get_topics(&self) -> Result<Vec<TopicSummary>, String>;
    async fn get_topic_detail(&self, name: &str) -> Result<TopicDetail, String>;
    async fn create_topic(&self, request: CreateTopicRequest) -> Result<(), String>;
    async fn delete_topic(&self, name: &str) -> Result<(), String>;

    // ============ Consumer 操作 ============
    async fn get_consumer_groups(&self) -> Result<Vec<ConsumerGroupSummary>, String>;
    async fn get_consumer_group_detail(&self, group_id: &str) -> Result<ConsumerGroupDetail, String>;
    async fn delete_consumer_group(&self, group_id: &str) -> Result<(), String>;

    // ============ 消息操作 ============
    async fn browse_messages(&self, request: BrowseMessagesRequest) -> Result<Vec<Message>, String>;
    async fn produce_message(&self, request: ProduceMessageRequest) -> Result<ProduceResult, String>;
}

    pub cluster_type: String,  // "kafka" | "rabbitmq" | "rocketmq"
    pub version: Option<String>,

    pub topics_count: usize,

    pub role: String,  // "controller" | "leader" | "follower" | "node"

}

/// Topic 概要（通用）
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct TopicSummary {
```

### 3.2 中间件服务管理器

```rust
// backend/src/services/middleware/mod.rs

pub mod traits;
pub mod kafka;
// pub mod rabbitmq;  // 未来扩展
// pub mod rocketmq;  // 未来扩展

use std::collections::HashMap;
use std::sync::Arc;
use tokio::sync::RwLock;
use crate::models::middleware::{MiddlewareConnectRequest, MiddlewareType};
use traits::MessageQueueDriver;

/// 中间件会话
pub struct MiddlewareSession {
    pub connection_id: String,
    pub middleware_type: MiddlewareType,
    pub driver: Arc<dyn MessageQueueDriver>,
    pub connected_at: chrono::DateTime<chrono::Utc>,
}

/// 中间件服务（连接池管理）
pub struct MiddlewareService {
    sessions: RwLock<HashMap<String, Arc<MiddlewareSession>>>,
}

impl MiddlewareService {
    pub fn new() -> Self {
        Self {
            sessions: RwLock::new(HashMap::new()),
        }
    }

    /// 连接中间件
    pub async fn connect(&self, request: MiddlewareConnectRequest) -> Result<ClusterInfo, String> {
        let driver: Arc<dyn MessageQueueDriver> = match request.middleware_type {
            MiddlewareType::Kafka => {
                let config = request.kafka_config
                    .ok_or("Kafka config is required")?;
                Arc::new(kafka::KafkaDriver::connect(config).await?)
            }
            // MiddlewareType::RabbitMQ => {
            //     let config = request.rabbitmq_config.ok_or("RabbitMQ config is required")?;
            //     Arc::new(rabbitmq::RabbitMQDriver::connect(config).await?)
            // }
            _ => return Err(format!("Unsupported middleware type: {:?}", request.middleware_type)),
        };

        // 测试连接
        let cluster_info = driver.get_cluster_info().await?;

        // 保存会话
        let session = Arc::new(MiddlewareSession {
            connection_id: request.connection_id.clone(),
            middleware_type: request.middleware_type,
            driver,
            connected_at: chrono::Utc::now(),
        });

        self.sessions.write().await.insert(request.connection_id, session);

        Ok(cluster_info)
    }

    /// 获取会话
    pub async fn get_session(&self, connection_id: &str) -> Result<Arc<MiddlewareSession>, String> {
        self.sessions.read().await
            .get(connection_id)
            .cloned()
            .ok_or_else(|| format!("Connection not found: {}", connection_id))
    }

    /// 断开连接
    pub async fn disconnect(&self, connection_id: &str) -> Result<(), String> {
        if let Some(session) = self.sessions.write().await.remove(connection_id) {
            session.driver.disconnect().await?;
        }
        Ok(())
    }

    /// 断开所有连接
    pub async fn disconnect_all(&self) {
        let mut sessions = self.sessions.write().await;
        for (_, session) in sessions.drain() {
            let _ = session.driver.disconnect().await;
        }
    }
}
```

```rust
// backend/src/services/middleware/kafka/driver.rs

use rdkafka::admin::{AdminClient, AdminOptions, NewTopic, TopicReplication};
use rdkafka::client::DefaultClientContext;
use rdkafka::consumer::{BaseConsumer, Consumer};
use rdkafka::producer::FutureProducer;
use rdkafka::ClientConfig;
use std::sync::Arc;
use crate::services::middleware::traits::*;

pub struct KafkaDriver {
    admin: AdminClient<DefaultClientContext>,
    producer: FutureProducer,
    consumer: BaseConsumer,
    config: KafkaConfig,
}

impl KafkaDriver {
    pub async fn connect(config: KafkaConfig) -> Result<Self, String> {
        let mut client_config = ClientConfig::new();
        client_config.set("bootstrap.servers", config.bootstrap_servers.join(","));
        client_config.set("client.id", "zwd-opsbot");

        // 配置安全协议
        Self::configure_security(&mut client_config, &config)?;

        // 创建客户端
        let admin = client_config.create()
            .map_err(|e| format!("Failed to create admin client: {}", e))?;

        let producer = client_config.create()
            .map_err(|e| format!("Failed to create producer: {}", e))?;

        let consumer = client_config
            .clone()
            .set("group.id", format!("zwd-opsbot-browser-{}", uuid::Uuid::new_v4()))
            .create()
            .map_err(|e| format!("Failed to create consumer: {}", e))?;

        Ok(Self { admin, producer, consumer, config })
    }

    fn configure_security(config: &mut ClientConfig, kafka_config: &KafkaConfig) -> Result<(), String> {
        match kafka_config.security_protocol.as_deref() {
            Some("SASL_PLAINTEXT") => {
                config.set("security.protocol", "sasl_plaintext");
                Self::configure_sasl(config, kafka_config)?;
            }
            Some("SASL_SSL") => {
                config.set("security.protocol", "sasl_ssl");
                Self::configure_sasl(config, kafka_config)?;
                Self::configure_ssl(config, kafka_config)?;
            }
            Some("SSL") => {
                config.set("security.protocol", "ssl");
                Self::configure_ssl(config, kafka_config)?;
            }
            _ => {
                config.set("security.protocol", "plaintext");
            }
        }
        Ok(())
    }

    fn configure_sasl(config: &mut ClientConfig, kafka_config: &KafkaConfig) -> Result<(), String> {
        let mechanism = kafka_config.sasl_mechanism.as_deref().unwrap_or("PLAIN");
        config.set("sasl.mechanism", mechanism);

        if let (Some(username), Some(password)) = (&kafka_config.username, &kafka_config.password) {
            config.set("sasl.username", username);
            config.set("sasl.password", password);
        }
        Ok(())
    }

    fn configure_ssl(config: &mut ClientConfig, kafka_config: &KafkaConfig) -> Result<(), String> {
        if let Some(ca_cert) = &kafka_config.ssl_ca_cert {
            config.set("ssl.ca.location", ca_cert);
        }
        Ok(())
    }
}
```

### 4.3 状态管理

```typescript
// front/stores/middlewareStore.ts

import { create } from 'zustand';
import * as middlewareApi from '@/services/middleware';
import type { MiddlewareConnection } from '@/types/connection';
import type {
  KafkaClusterInfo,
  KafkaTopicSummary,
  KafkaTopicDetail,
  KafkaConsumerGroupSummary,
  KafkaConsumerGroupDetail,
  KafkaMessage,
} from '@/types/middleware';

interface MiddlewareState {
  // 当前连接
  currentConnection: MiddlewareConnection | null;

  // Kafka 数据
  clusterInfo: KafkaClusterInfo | null;
  topics: KafkaTopicSummary[];
  selectedTopic: KafkaTopicDetail | null;
  consumerGroups: KafkaConsumerGroupSummary[];
  selectedConsumerGroup: KafkaConsumerGroupDetail | null;
  messages: KafkaMessage[];

  // 加载状态
  loading: {
    cluster: boolean;
    topics: boolean;
    consumerGroups: boolean;
    messages: boolean;
  };

  // 刷新定时器
  refreshIntervals: Record<string, NodeJS.Timeout>;

  // Actions
  connect: (connection: MiddlewareConnection) => Promise<void>;
  disconnect: () => Promise<void>;
  loadClusterInfo: () => Promise<void>;
  loadTopics: () => Promise<void>;
  loadTopicDetail: (topicName: string) => Promise<void>;
  createTopic: (name: string, partitions: number, replicationFactor: number) => Promise<void>;
  deleteTopic: (topicName: string) => Promise<void>;
  loadConsumerGroups: () => Promise<void>;
  loadConsumerGroupDetail: (groupId: string) => Promise<void>;
  deleteConsumerGroup: (groupId: string) => Promise<void>;
  browseMessages: (topic: string, partition?: number, offset?: number, limit?: number) => Promise<void>;
  produceMessage: (topic: string, value: string, key?: string) => Promise<void>;
  startAutoRefresh: () => void;
  stopAutoRefresh: () => void;
  reset: () => void;
}

const initialState = {
  currentConnection: null,
  clusterInfo: null,
  topics: [],
  selectedTopic: null,
  consumerGroups: [],
  selectedConsumerGroup: null,
  messages: [],
  loading: {
    cluster: false,
    topics: false,
    consumerGroups: false,
    messages: false,
  },
  refreshIntervals: {},
};

export const useMiddlewareStore = create<MiddlewareState>((set, get) => ({
  ...initialState,

  connect: async (connection) => {
    const { disconnect } = get();
    await disconnect();

    try {
      await middlewareApi.middlewareConnect({
        connectionId: connection.id,
        middlewareType: connection.middlewareType,
        kafkaConfig: connection.kafkaConfig,
      });

      set({ currentConnection: connection });

      // 加载初始数据
      await Promise.all([
        get().loadClusterInfo(),
        get().loadTopics(),
        get().loadConsumerGroups(),
      ]);

      get().startAutoRefresh();
    } catch (error) {
      console.error('Failed to connect:', error);
      throw error;
    }
  },

  disconnect: async () => {
    const { currentConnection, stopAutoRefresh } = get();
    stopAutoRefresh();

    if (currentConnection) {
      try {
        await middlewareApi.middlewareDisconnect(currentConnection.id);
      } catch (e) {
        console.error('Failed to disconnect:', e);
      }
    }

    set(initialState);
  },

  loadClusterInfo: async () => {
    const { currentConnection } = get();
    if (!currentConnection) return;

    set(s => ({ loading: { ...s.loading, cluster: true } }));
    try {
      const clusterInfo = await middlewareApi.getClusterInfo(currentConnection.id);
      set({ clusterInfo });
    } catch (error) {
      console.error('Failed to load cluster info:', error);
    } finally {
      set(s => ({ loading: { ...s.loading, cluster: false } }));
    }
  },

  loadTopics: async () => {
    const { currentConnection } = get();
    if (!currentConnection) return;

    set(s => ({ loading: { ...s.loading, topics: true } }));
    try {
      const topics = await middlewareApi.getTopics(currentConnection.id);
      set({ topics });
    } catch (error) {
      console.error('Failed to load topics:', error);
    } finally {
      set(s => ({ loading: { ...s.loading, topics: false } }));
    }
  },

  loadTopicDetail: async (topicName) => {
    const { currentConnection } = get();
    if (!currentConnection) return;

    try {
      const detail = await middlewareApi.getTopicDetail(currentConnection.id, topicName);
      set({ selectedTopic: detail });
    } catch (error) {
      console.error('Failed to load topic detail:', error);
    }
  },

  createTopic: async (name, partitions, replicationFactor) => {
    const { currentConnection, loadTopics } = get();
    if (!currentConnection) return;

    await middlewareApi.createTopic(currentConnection.id, name, partitions, replicationFactor);
    await loadTopics();
  },

  deleteTopic: async (topicName) => {
    const { currentConnection, loadTopics } = get();
    if (!currentConnection) return;

    await middlewareApi.deleteTopic(currentConnection.id, topicName);
    set({ selectedTopic: null });
    await loadTopics();
  },

  loadConsumerGroups: async () => {
    const { currentConnection } = get();
    if (!currentConnection) return;

    set(s => ({ loading: { ...s.loading, consumerGroups: true } }));
    try {
      const consumerGroups = await middlewareApi.getConsumerGroups(currentConnection.id);
      set({ consumerGroups });
    } catch (error) {
      console.error('Failed to load consumer groups:', error);
    } finally {
      set(s => ({ loading: { ...s.loading, consumerGroups: false } }));
    }
  },

  loadConsumerGroupDetail: async (groupId) => {
    const { currentConnection } = get();
    if (!currentConnection) return;

    try {
      const detail = await middlewareApi.getConsumerGroupDetail(currentConnection.id, groupId);
      set({ selectedConsumerGroup: detail });
    } catch (error) {
      console.error('Failed to load consumer group detail:', error);
    }
  },

  deleteConsumerGroup: async (groupId) => {
    const { currentConnection, loadConsumerGroups } = get();
    if (!currentConnection) return;

    await middlewareApi.deleteConsumerGroup(currentConnection.id, groupId);
    set({ selectedConsumerGroup: null });
    await loadConsumerGroups();
  },

  browseMessages: async (topic, partition, offset, limit = 100) => {
    const { currentConnection } = get();
    if (!currentConnection) return;

    set(s => ({ loading: { ...s.loading, messages: true } }));
    try {
      const messages = await middlewareApi.browseMessages(currentConnection.id, {
        topic,
        partition,
        offset,
        limit,
      });
      set({ messages });
    } catch (error) {
      console.error('Failed to browse messages:', error);
    } finally {
      set(s => ({ loading: { ...s.loading, messages: false } }));
    }
  },

  produceMessage: async (topic, value, key) => {
    const { currentConnection } = get();
    if (!currentConnection) return;

    await middlewareApi.produceMessage(currentConnection.id, { topic, value, key });
  },

  startAutoRefresh: () => {
    const intervals: Record<string, NodeJS.Timeout> = {};

    intervals.topics = setInterval(() => get().loadTopics(), 30000);
    intervals.consumerGroups = setInterval(() => get().loadConsumerGroups(), 15000);
    intervals.cluster = setInterval(() => get().loadClusterInfo(), 60000);

    set({ refreshIntervals: intervals });
  },

  stopAutoRefresh: () => {
    const { refreshIntervals } = get();
    Object.values(refreshIntervals).forEach(clearInterval);
    set({ refreshIntervals: {} });
  },

  reset: () => {
    get().stopAutoRefresh();
    set(initialState);
  },
}));
```

## 6. 扩展性设计

### 6.1 添加新消息队列的步骤

以添加 RabbitMQ 为例：

**1. 更新类型定义**
```typescript
// front/types/connection.ts
export type MiddlewareType = 'redis' | 'kafka' | 'elasticsearch' | 'rabbitmq'

export interface MiddlewareConnection {
  // ...
  rabbitmqConfig?: {
    host: string
    port: number
    vhost: string
    username?: string
    password?: string
  }
}
```

**2. 实现后端 Driver**
```rust
// backend/src/services/middleware/rabbitmq/driver.rs
pub struct RabbitMQDriver { /* ... */ }

#[async_trait]
impl MessageQueueDriver for RabbitMQDriver {
    // 实现 trait 中的所有方法
}
```

**3. 注册到 MiddlewareService**
```rust
// backend/src/services/middleware/mod.rs
MiddlewareType::RabbitMQ => {
    let config = request.rabbitmq_config.ok_or("RabbitMQ config required")?;
    Arc::new(rabbitmq::RabbitMQDriver::connect(config).await?)
}
```

**4. 创建前端组件**
```
front/components/middleware/rabbitmq/
├── RabbitMQOverview.tsx
├── RabbitMQQueues.tsx
├── RabbitMQExchanges.tsx
└── RabbitMQBindings.tsx
```

### 6.2 通用与特有功能分离

| 通用功能（trait 定义） | Kafka 特有 | RabbitMQ 特有 |
|----------------------|-----------|--------------|
| get_topics/queues | Partitions | Durable/Exclusive |
| produce_message | Headers | Routing Key |
| consume_message | Offset | Ack Mode |
| get_consumer_groups | Lag 监控 | Prefetch Count |
