# ER 图设计器 Phase 2: 完善编辑功能

## 概述

本文档描述 ER 图设计器 Phase 2 的开发计划，主要包含表结构编辑面板、索引管理、外键关系编辑和撤销/重做功能。

## 当前状态

Phase 1 已完成的功能：
- SVG 画布渲染和缩放/平移
- 表节点显示和拖拽移动
- 关系线渲染（贝塞尔曲线）
- 基础属性面板（表名、注释、颜色、字段列表）
- MySQL/PostgreSQL SQL 生成器
- Zustand 状态管理（diagramStore）
- 本地持久化存储

**目标**: 完善现有属性面板，支持完整的字段属性编辑

### 3. 外键关系编辑

**目标**: 支持可视化创建和编辑表之间的外键关系

#### 3.1 关系数据结构

```typescript
// 已定义在 types.ts
interface Relationship {
  id: string
  name: string
  startTableId: string
  startFieldId: string
  endTableId: string
  endFieldId: string
  cardinality: 'one_to_one' | 'one_to_many' | 'many_to_one'
  updateConstraint: ConstraintAction
  deleteConstraint: ConstraintAction
}
```

#### 3.2 创建关系的交互方式

**方式 A: 拖拽连线**
1. 鼠标悬停在字段上显示连接点
2. 从连接点拖拽到另一个表的字段
3. 松开鼠标创建关系

**方式 B: 右键菜单**
1. 右键点击字段 → "Create Foreign Key"
2. 弹出对话框选择目标表和字段

#### 3.3 关系属性面板

```
┌─────────────────────────────────────┐
│ Relationship Properties             │
├─────────────────────────────────────┤
│ Name: [fk_orders_user_id___]        │
│                                     │
│ From: orders.user_id                │
│ To:   users.id                      │
│                                     │
│ Cardinality: [Many to One ▼]        │
│                                     │
│ ON UPDATE: [NO ACTION ▼]            │
│ ON DELETE: [CASCADE ▼]              │
│                                     │
│           [Delete]  [Close]         │
└─────────────────────────────────────┘
```

#### 3.4 实现步骤

1. **添加字段连接点**
   - 修改 TableNode 组件
   - 鼠标悬停时显示右侧连接圆点
   - 拖拽开始时进入连线模式

2. **连线模式实现**
   - 在 ERDiagramCanvas 中管理连线状态
   - 拖拽时绘制临时连线
   - 松开时创建 Relationship

3. **关系属性面板**
   - 选中关系线时显示属性面板
   - 支持编辑基数和约束

4. **关系线样式**
   - 根据基数显示不同端点标记（乌鸦脚记号）
   - 选中时高亮显示

### 4. 撤销/重做功能

**目标**: 实现操作历史记录，支持撤销和重做

#### 4.1 设计方案

**方案选择: 快照模式**

由于图表数据量不大，采用全量快照存储历史状态，实现简单可靠。

```typescript
interface DiagramHistory {
  past: DiagramData[]      // 历史状态栈
  present: DiagramData     // 当前状态
  future: DiagramData[]    // 重做状态栈
}
```

#### 4.2 实现要点

1. **历史记录存储**
   - 每次状态变更时保存快照
   - 限制历史记录数量（如最多 50 条）

2. **触发保存的时机**
   - 表/字段/索引/关系的增删改
   - 表拖拽结束时（不是每次 move）

3. **忽略的操作**
   - 画布平移/缩放
   - 选择状态变更

#### 4.3 Zustand 集成

```typescript
// diagramStore.ts 扩展

interface DiagramState {
  // ... 现有状态

  // 历史记录
  past: DiagramData[]
  future: DiagramData[]

  // 历史操作
  undo: () => void
  redo: () => void
  canUndo: () => boolean
  canRedo: () => boolean

  // 内部方法
  pushHistory: () => void
}
```

#### 4.4 工具栏集成

- 添加撤销/重做按钮
- 快捷键: Ctrl+Z / Ctrl+Y (Windows), Cmd+Z / Cmd+Shift+Z (Mac)

#### 4.5 文件清单

| `stores/diagramStore.ts` | 修改 | 添加历史记录逻辑 |

## 验收标准

### 表结构编辑
- [ ] 可编辑字段的 size、precision、scale
- [ ] 可设置字段默认值
- [ ] 可设置 CHECK 约束
- [ ] 可添加字段注释

### 索引管理
- [ ] 可添加新索引
- [ ] 可编辑索引名称、类型、字段
- [ ] 可设置唯一索引
- [ ] 可删除索引

### 外键关系编辑
- [ ] 可通过拖拽创建表关系
- [ ] 可编辑关系名称
- [ ] 可选择基数类型 (1:1, 1:N, N:1)
- [ ] 可设置 ON UPDATE / ON DELETE 约束
- [ ] 可删除关系
- [ ] 关系线显示正确的基数标记

### 撤销/重做
- [ ] 撤销可恢复上一步操作
- [ ] 重做可恢复撤销的操作
- [ ] 快捷键 Ctrl+Z / Ctrl+Y 正常工作
- [ ] 工具栏按钮状态正确（禁用/启用）
- [ ] 历史记录不包含画布平移/缩放操作
