# ClickHouse 数据库完整支持设计文档

## 1. 概述

### 1.1 目标
为 ZWD-OpsBot 添加完整的 ClickHouse 数据库支持，实现：
- 连接管理（单机/集群）
- 数据库和表浏览
- 表结构查看（列、索引、分区）
- 数据查询和导出
- SQL 编辑器
- ER 图设计器适配

### 1.2 ClickHouse 简介
ClickHouse 是由 Yandex 开发的开源列式数据库管理系统（DBMS），专为在线分析处理（OLAP）设计。它能够使用 SQL 查询实时生成分析报告，具有极高的查询性能。

#### 核心特点
- **列式存储**：数据按列存储，适合分析查询
- **实时分析**：支持实时数据插入和即时查询
- **高压缩比**：列式存储带来高效压缩
- **向量化执行**：利用 CPU SIMD 指令加速
- **分布式架构**：支持数据分片和复制
- **SQL 兼容**：标准 SQL 语法 + ClickHouse 扩展

### 1.3 ClickHouse 与传统 RDBMS 的差异

| 特性 | ClickHouse | MySQL/PostgreSQL |
|-----|------------|------------------|
| **存储模型** | 列式 | 行式 |
| **适用场景** | OLAP（分析） | OLTP（事务） |
| **事务支持** | 有限（无完整 ACID） | 完整 ACID |
| **UPDATE/DELETE** | 异步 Mutation | 即时执行 |
| **主键** | 排序键（ORDER BY） | 传统主键 |
| **索引** | 稀疏索引 | B-Tree/Hash |
| **表引擎** | 多种（MergeTree 系列） | 固定（InnoDB 等） |
| **分区** | 原生支持 | 需扩展 |
| **复制** | 内置 ZooKeeper 复制 | 主从复制 |

### 1.4 支持的版本
- ClickHouse 21.x 及以上（推荐 23.x+）

### 1.5 连接协议
- **HTTP(S)**: 端口 8123（默认）
- **Native TCP**: 端口 9000（高性能）
- **MySQL 协议**: 端口 9004（兼容 MySQL 客户端）

### 4.5 分布式表设计

#### 4.5.1 本地表 vs 分布式表

在 ClickHouse 集群环境中，表分为两类：

| 表类型 | 引擎 | 说明 | 数据存储 |
|-------|------|-----|---------|
| **本地表** | MergeTree 系列 | 实际存储数据的表 | 存储在单个节点 |
| **分布式表** | Distributed | 虚拟表，路由查询到多个本地表 | 不存储数据 |

#### 4.5.2 分布式表工作原理

```
┌─────────────────────────────────────────────────────────┐
│                    分布式表 (Distributed)                 │
│                  db.events_distributed                   │
└─────────────────────┬───────────────────────────────────┘
                      │ 查询路由
          ┌───────────┼───────────┐
          ▼           ▼           ▼
    ┌──────────┐ ┌──────────┐ ┌──────────┐
    │ Shard 1  │ │ Shard 2  │ │ Shard 3  │
    │ 本地表    │ │ 本地表    │ │ 本地表    │
    │ db.events│ │ db.events│ │ db.events│
    └──────────┘ └──────────┘ └──────────┘
```

#### 4.5.3 分布式表 SQL 语法

```sql
-- 方式1：基于已有本地表创建
CREATE TABLE db.events_distributed ON CLUSTER cluster_name
AS db.events_local
ENGINE = Distributed(cluster_name, db, events_local, sharding_key)

-- 方式2：完整定义（会同时创建本地表结构）
CREATE TABLE db.events_distributed ON CLUSTER cluster_name (
    event_id UInt64,
    user_id UInt64,
    event_time DateTime,
    event_type String
) ENGINE = Distributed(cluster_name, db, events_local, xxHash64(user_id))

-- 参数说明：
-- cluster_name: 集群名称（在 config.xml 中定义）
-- db: 本地表所在数据库
-- events_local: 本地表名
-- sharding_key: 分片键表达式
```

#### 4.5.4 常用分片键

| 分片键 | 说明 | 适用场景 |
|-------|------|---------|
| `rand()` | 随机分片 | 均匀分布，无特定查询模式 |
| `xxHash64(user_id)` | 用户ID哈希 | 按用户聚合查询 |
| `intHash64(order_id)` | 订单ID哈希 | 按订单聚合查询 |
| `toYYYYMM(date)` | 按月分片 | 时间序列数据 |
| `cityHash64(region)` | 区域哈希 | 地理分区数据 |

#### 5.2.2 ClickHouse 驱动实现

```rust
// backend/src/services/database/clickhouse.rs

use async_trait::async_trait;
use clickhouse::{Client, Row};
use serde::Deserialize;

use crate::models::*;
use super::traits::DatabaseDriver;

/// ClickHouse 数据库驱动
pub struct ClickHouseDriver {
    client: Client,
    current_database: String,
}

impl ClickHouseDriver {
    /// 创建连接
    pub async fn connect(
        host: &str,
        port: u16,
        username: &str,
        password: Option<&str>,
        database: Option<&str>,
    ) -> Result<Self, String> {
        let url = format!("http://{}:{}", host, port);

        let mut client = Client::default()
            .with_url(&url)
            .with_user(username);

        if let Some(pwd) = password {
            client = client.with_password(pwd);
        }

        if let Some(db) = database {
            client = client.with_database(db);
        }

        // 测试连接
        client.query("SELECT 1")
            .fetch_one::<u8>()
            .await
            .map_err(|e| format!("Connection failed: {}", e))?;

        log::info!("Connected to ClickHouse: {}", url);

        Ok(Self {
            client,
            current_database: database.unwrap_or("default").to_string(),
        })
    }

    /// 测试连接
    pub async fn test_connection(
        host: &str,
        port: u16,
        username: &str,
        password: Option<&str>,
    ) -> Result<(), String> {
        let driver = Self::connect(host, port, username, password, None).await?;
        drop(driver);
        Ok(())
    }
}

#[derive(Row, Deserialize)]
struct DatabaseRow {
    name: String,
}

#[derive(Row, Deserialize)]
struct TableRow {
    name: String,
    engine: String,
    total_rows: Option<u64>,
    total_bytes: Option<u64>,
}

#[derive(Row, Deserialize)]
struct ColumnRow {
    name: String,
    #[serde(rename = "type")]
    column_type: String,
    default_kind: String,
    default_expression: String,
    comment: String,
    compression_codec: String,
    is_in_sorting_key: u8,
    is_in_primary_key: u8,
    is_in_partition_key: u8,
}

#[async_trait]
impl DatabaseDriver for ClickHouseDriver {
    async fn get_databases(&self) -> Result<Vec<String>, String> {
        let sql = "SELECT name FROM system.databases ORDER BY name";

        let rows = self.client.query(sql)
            .fetch_all::<DatabaseRow>()
            .await
            .map_err(|e| e.to_string())?;

        Ok(rows.into_iter().map(|r| r.name).collect())
    }

    async fn get_schemas(&self, _database: Option<&str>) -> Result<Vec<String>, String> {
        // ClickHouse 没有 schema 概念
        Ok(vec!["default".to_string()])
    }

    async fn get_tables(
        &self,
        database: &str,
        _schema: Option<&str>,
    ) -> Result<Vec<TableInfo>, String> {
        let sql = format!(r#"
            SELECT
                name,
                engine,
                total_rows,
                total_bytes
            FROM system.tables
            WHERE database = '{}'
              AND engine != 'View'
            ORDER BY name
        "#, database);

        let rows = self.client.query(&sql)
            .fetch_all::<TableRow>()
            .await
            .map_err(|e| e.to_string())?;

        Ok(rows.into_iter().map(|r| TableInfo {
            name: r.name,
            table_type: r.engine,
            row_count: r.total_rows,
        }).collect())
    }

    async fn get_table_structure(
        &self,
        database: &str,
        table: &str,
    ) -> Result<TableStructure, String> {
        let sql = format!(r#"
            SELECT
                name,
                type,
                default_kind,
                default_expression,
                comment,
                compression_codec,
                is_in_sorting_key,
                is_in_primary_key,
                is_in_partition_key
            FROM system.columns
            WHERE database = '{}' AND table = '{}'
            ORDER BY position
        "#, database, table);

        let rows = self.client.query(&sql)
            .fetch_all::<ColumnRow>()
            .await
            .map_err(|e| e.to_string())?;

        let columns: Vec<ColumnDetail> = rows.into_iter().map(|r| {
            let key = if r.is_in_primary_key == 1 {
                Some("PRI".to_string())
            } else if r.is_in_sorting_key == 1 {
                Some("SORT".to_string())
            } else {
                None
            };

            let default_value = if !r.default_expression.is_empty() {
                Some(r.default_expression)
            } else {
                None
            };

            let extra = if r.is_in_partition_key == 1 {
                Some("PARTITION".to_string())
            } else if !r.compression_codec.is_empty() {
                Some(r.compression_codec)
            } else {
                None
            };

            ColumnDetail {
                name: r.name,
                column_type: r.column_type,
                nullable: r.column_type.starts_with("Nullable"),
                key,
                default_value,
                extra,
                comment: if r.comment.is_empty() { None } else { Some(r.comment) },
            }
        }).collect();

        Ok(TableStructure {
            database: database.to_string(),
            table_name: table.to_string(),
            columns,
            indexes: vec![],  // ClickHouse 索引通过 ORDER BY 定义
        })
    }

    async fn get_views(
        &self,
        database: &str,
        _schema: Option<&str>,
    ) -> Result<Vec<ViewInfo>, String> {
        let sql = format!(r#"
            SELECT name
            FROM system.tables
            WHERE database = '{}'
              AND (engine = 'View' OR engine = 'MaterializedView')
            ORDER BY name
        "#, database);

        let rows = self.client.query(&sql)
            .fetch_all::<DatabaseRow>()
            .await
            .map_err(|e| e.to_string())?;

        Ok(rows.into_iter().map(|r| ViewInfo {
            name: r.name,
            definer: None,
            security_type: None,
        }).collect())
    }

    async fn get_routines(
        &self,
        _database: &str,
        _schema: Option<&str>,
    ) -> Result<Vec<RoutineInfo>, String> {
        // ClickHouse 不支持存储过程
        Ok(vec![])
    }

    async fn get_table_ddl(
        &self,
        database: &str,
        table: &str,
    ) -> Result<String, String> {
        let sql = format!("SHOW CREATE TABLE {}.{}", database, table);

        #[derive(Row, Deserialize)]
        struct CreateRow {
            statement: String,
        }

        let row = self.client.query(&sql)
            .fetch_one::<CreateRow>()
            .await
            .map_err(|e| e.to_string())?;

        Ok(row.statement)
    }

    async fn get_foreign_keys(
        &self,
        _database: &str,
        _table: &str,
    ) -> Result<Vec<ForeignKeyInfo>, String> {
        // ClickHouse 不支持外键
        Ok(vec![])
    }

    async fn get_check_constraints(
        &self,
        _database: &str,
        _table: &str,
    ) -> Result<Vec<CheckConstraintInfo>, String> {
        // ClickHouse 不支持 CHECK 约束
        Ok(vec![])
    }

    async fn get_triggers(
        &self,
        _database: &str,
        _table: &str,
    ) -> Result<Vec<TriggerInfo>, String> {
        // ClickHouse 不支持触发器
        Ok(vec![])
    }

    async fn get_table_options(
        &self,
        database: &str,
        table: &str,
    ) -> Result<TableOptions, String> {
        let sql = format!(r#"
            SELECT engine, engine_full, partition_key, sorting_key, primary_key
            FROM system.tables
            WHERE database = '{}' AND name = '{}'
        "#, database, table);

        #[derive(Row, Deserialize)]
        struct EngineRow {
            engine: String,
            engine_full: String,
            partition_key: String,
            sorting_key: String,
            primary_key: String,
        }

        let row = self.client.query(&sql)
            .fetch_one::<EngineRow>()
            .await
            .map_err(|e| e.to_string())?;

        Ok(TableOptions {
            engine: row.engine,
            charset: "UTF-8".to_string(),
            collation: "".to_string(),
            comment: format!("ORDER BY: {}", row.sorting_key),
            auto_increment: None,
            row_format: Some(row.engine_full),
        })
    }

    async fn execute_query(&self, sql: &str) -> Result<QueryResult, String> {
        let start = std::time::Instant::now();

        // 使用 format=JSONEachRow 获取结果
        let result_json = self.client
            .query(sql)
            .with_option("format", "JSONCompact")
            .fetch_all::<serde_json::Value>()
            .await
            .map_err(|e| e.to_string())?;

        let execution_time = start.elapsed().as_millis() as u64;

        // 解析 JSON 结果
        // 注意：实际实现需要更复杂的类型处理
        let rows: Vec<Vec<serde_json::Value>> = result_json
            .into_iter()
            .map(|v| {
                if let serde_json::Value::Array(arr) = v {
                    arr
                } else {
                    vec![v]
                }
            })
            .collect();

        Ok(QueryResult {
            columns: vec![],  // 需要从结果元数据获取
            rows,
            affected_rows: 0,
            execution_time_ms: execution_time,
        })
    }

    async fn execute_update(&self, sql: &str) -> Result<QueryResult, String> {
        let start = std::time::Instant::now();

        self.client.query(sql)
            .execute()
            .await
            .map_err(|e| e.to_string())?;

        let execution_time = start.elapsed().as_millis() as u64;

        Ok(QueryResult {
            columns: vec![],
            rows: vec![],
            affected_rows: 0,  // ClickHouse 不返回影响行数
            execution_time_ms: execution_time,
        })
    }

    async fn rename_table(
        &self,
        database: &str,
        old_name: &str,
        new_name: &str,
    ) -> Result<(), String> {
        let sql = format!(
            "RENAME TABLE {}.{} TO {}.{}",
            database, old_name, database, new_name
        );

        self.client.query(&sql)
            .execute()
            .await
            .map_err(|e| e.to_string())?;

        Ok(())
    }

    async fn drop_table(&self, database: &str, table: &str) -> Result<(), String> {
        let sql = format!("DROP TABLE IF EXISTS {}.{}", database, table);

        self.client.query(&sql)
            .execute()
            .await
            .map_err(|e| e.to_string())?;

        Ok(())
    }

    async fn get_objects_count(
        &self,
        database: &str,
        _schema: Option<&str>,
    ) -> Result<DatabaseObjectsCount, String> {
        let sql = format!(r#"
            SELECT
                countIf(engine NOT IN ('View', 'MaterializedView')) as tables,
                countIf(engine = 'View') as views,
                countIf(engine = 'MaterializedView') as mat_views
            FROM system.tables
            WHERE database = '{}'
        "#, database);

        #[derive(Row, Deserialize)]
        struct CountRow {
            tables: u64,
            views: u64,
            mat_views: u64,
        }

        let row = self.client.query(&sql)
            .fetch_one::<CountRow>()
            .await
            .map_err(|e| e.to_string())?;

        Ok(DatabaseObjectsCount {
            tables: row.tables as usize,
            views: (row.views + row.mat_views) as usize,
            functions: 0,
            procedures: 0,
        })
    }

    pub async fn get_clusters(&self) -> Result<Vec<ClusterInfo>, String> {
        let sql = r#"
            SELECT
                cluster,
                shard_num,
                replica_num,
                host_name,
                port
            FROM system.clusters
            ORDER BY cluster, shard_num, replica_num
        "#;

        #[derive(Row, Deserialize)]
        struct ClusterRow {
            cluster: String,
            shard_num: u32,
            replica_num: u32,
            host_name: String,
            port: u16,
        }

        let rows = self.client.query(sql)
            .fetch_all::<ClusterRow>()
            .await
            .map_err(|e| e.to_string())?;

        // 按集群分组
        let mut clusters: std::collections::HashMap<String, ClusterInfo> =
            std::collections::HashMap::new();

        for row in rows {
            let cluster = clusters.entry(row.cluster.clone()).or_insert_with(|| {

                    name: row.cluster.clone(),
                    shards: vec![],
                }
            });

            // 简化处理：只记录节点

                replica_num: row.replica_num,
                host: row.host_name,
                port: row.port,

            .await
            .map_err(|e| format!("Failed to create distributed table: {}", e))?;

        Ok(())

        &self,

        table_name: &str,
        cluster: &str,
        columns_sql: &str,
        engine: &str,
        order_by: &str,
        partition_by: Option<&str>,
    ) -> Result<(), String> {

            database, table_name, cluster, columns_sql, engine

        self.client.query(&sql)
            .execute()
            .await
            .map_err(|e| format!("Failed to create local table on cluster: {}", e))?;

        Ok(())
    }
```

```typescript
// front/utils/sql-generator/clickhouse.ts

import { DiagramData, TableNode, TableField } from '@/components/database/designer/types'
import { escapeQuotes } from './shared'

/**
 * 生成 ClickHouse DDL
 */
export function toClickHouse(diagram: DiagramData): string {
  const statements: string[] = []

  // 头部注释
  statements.push('-- ClickHouse DDL')
  statements.push('-- Generated by ZWD-OpsBot')
  statements.push('')

  // 生成表定义
  diagram.tables.forEach((table) => {
    statements.push(generateTableSQL(table, diagram))
  })

  return statements.join('\n')
}

/**
 * 生成单个表的 CREATE TABLE 语句
 */
function generateTableSQL(table: TableNode, diagram: DiagramData): string {
  const lines: string[] = []

  // 字段定义
  table.fields.forEach((field) => {
    lines.push(generateFieldSQL(field))
  })

  // ClickHouse 表引擎和排序键
  const engine = table.options?.engine || 'MergeTree'
  const orderByFields = table.fields
    .filter((f) => f.primary)
    .map((f) => `\`${f.name}\``)
  const orderBy = orderByFields.length > 0
    ? orderByFields.join(', ')
    : '`id`'  // 默认

  // 分区键（可选）
  const partitionBy = table.options?.partitionBy || ''

  // 组装 CREATE TABLE
  let sql = `CREATE TABLE IF NOT EXISTS \`${table.name}\` (\n`
  sql += lines.join(',\n')
  sql += '\n)'
  sql += `\nENGINE = ${engine}`

  if (partitionBy) {
    sql += `\nPARTITION BY ${partitionBy}`
  }

  sql += `\nORDER BY (${orderBy})`

  // 表注释
  if (table.comment) {
    sql += `\nCOMMENT '${escapeQuotes(table.comment)}'`
  }

  sql += ';'

  return sql
}

/**
 * 生成单个字段定义
 */
function generateFieldSQL(field: TableField): string {
  let def = `\t\`${field.name}\` ${formatDataType(field)}`

  // ClickHouse 使用 Nullable 包装而非 NOT NULL
  // 默认非空，使用 Nullable(Type) 表示可空

  // DEFAULT
  if (field.default !== '' && field.default !== undefined) {
    def += ` DEFAULT ${formatDefault(field)}`
  }

  // CODEC（压缩）
  if (field.options?.codec) {
    def += ` CODEC(${field.options.codec})`
  }

  // TTL
  if (field.options?.ttl) {
    def += ` TTL ${field.options.ttl}`
  }

  // 注释
  if (field.comment) {
    def += ` COMMENT '${escapeQuotes(field.comment)}'`
  }

  return def
}

/**
 * 格式化数据类型
 */
function formatDataType(field: TableField): string {
  let type = field.type

  // 处理 Nullable
  if (!field.notNull) {
    // 对于需要尺寸的类型
    if (field.size && ['FixedString', 'Decimal32', 'Decimal64', 'Decimal128', 'DateTime64'].includes(type)) {
      type = `${type}(${field.size})`
    } else if (field.precision && field.scale !== undefined && type === 'Decimal') {
      type = `Decimal(${field.precision}, ${field.scale})`
    }
    return `Nullable(${type})`
  }

  // 处理尺寸
  if (field.size && ['FixedString', 'Decimal32', 'Decimal64', 'Decimal128', 'DateTime64'].includes(type)) {
    return `${type}(${field.size})`
  }

  if (field.precision && field.scale !== undefined && type === 'Decimal') {
    return `Decimal(${field.precision}, ${field.scale})`
  }

  return type
}

/**
 * 格式化默认值
 */
function formatDefault(field: TableField): string {
  const value = field.default
  if (!value) return ''

  const upper = value.toUpperCase()

  // ClickHouse 函数
  const functions = [
    'NOW()', 'TODAY()', 'YESTERDAY()',
    'GENERATEUUIDV4()', 'RAND()', 'RAND64()',
  ]
  if (functions.some(f => upper.startsWith(f.replace('()', '')))) {
    return value
  }

  // 数值类型
  const numericTypes = [
    'Int8', 'Int16', 'Int32', 'Int64', 'Int128', 'Int256',
    'UInt8', 'UInt16', 'UInt32', 'UInt64', 'UInt128', 'UInt256',
    'Float32', 'Float64', 'Decimal',
  ]
  if (numericTypes.some(t => field.type.startsWith(t))) {
    return value
  }

  // 布尔
  if (field.type === 'Bool') {
    return value.toLowerCase() === 'true' ? 'true' : 'false'
  }

  // 字符串类型
  return `'${escapeQuotes(value)}'`
}

export default toClickHouse
```

## 8. ClickHouse 特有注意事项

### 8.1 无外键约束
ClickHouse 是分析型数据库，不支持外键约束。ER 图设计器中的关系仅用于文档和可视化，不会生成外键 DDL。

### 8.2 ORDER BY 必需
MergeTree 系列引擎必须指定 ORDER BY（排序键），这决定了数据的物理存储顺序和主键。

### 8.3 Mutation 操作
UPDATE 和 DELETE 通过 ALTER TABLE ... UPDATE/DELETE 执行，是异步操作：
```sql
ALTER TABLE table UPDATE column = value WHERE condition;
ALTER TABLE table DELETE WHERE condition;
```

### 8.4 分区管理
- 按时间分区最常见（按日/月）
- 可以 DETACH/ATTACH 分区
- 可以 DROP PARTITION 删除数据

### 8.5 数据类型差异
- 使用 `Nullable(Type)` 表示可空，而非 `NOT NULL`
- 数组使用 `Array(Type)` 语法
- 嵌套结构使用 `Nested(...)`
