# Phase 1: 数据库设计器基础架构实现计划

> 版本：v1.0
> 创建日期：2025-12-21
> 模块目标：ER 图可视化设计器基础架构

---

## 1. 目标

实现 ER 图可视化设计器的基础架构，包括 SVG 画布、表节点拖拽、状态管理和 MySQL/PostgreSQL SQL 生成器。

## 2. Phase 1 任务清单

1. 创建 ER 图画布组件 (SVG)
2. 实现表节点拖拽和连线
3. 实现基础状态管理 (Zustand)
4. 集成 MySQL/PostgreSQL SQL 生成器

---

## 3. 实现步骤

### 3.1 创建类型定义 (types.ts)

**文件**: `front/components/database/designer/types.ts`

定义核心数据结构：
- `DatabaseDialect` - 支持的数据库类型
- `TableField` - 字段定义
- `TableIndex` - 索引定义
- `TableNode` - 表节点（含位置坐标）
- `Relationship` - 表关系/外键
- `DiagramData` - 完整图表数据

### 3.2 创建 diagramStore (Zustand)

**文件**: `front/stores/diagramStore.ts`

状态管理：
- 图表数据 (tables, relationships)
- 选中状态 (selectedTableId, selectedRelationshipId)
- 编辑状态 (isDirty)
- 历史记录 (history, historyIndex) - Phase 2 完善

Actions:
- `setDatabase` - 切换目标数据库
- `addTable/updateTable/deleteTable/moveTable` - 表操作
- `addField/updateField/deleteField` - 字段操作
- `addRelationship/updateRelationship/deleteRelationship` - 关系操作
- `selectTable/clearSelection` - 选择操作
- `loadDiagram/exportDiagram` - 导入导出

### 3.3 创建 SVG 画布组件

**文件**: `front/components/database/designer/ERDiagramCanvas.tsx`

核心功能：
- SVG 容器，支持缩放和平移
- 渲染表节点 (TableNode 组件)
- 渲染关系线 (RelationshipLine 组件)
- 点击空白区域取消选择
- 网格背景（可选）

### 3.4 创建表节点组件

**文件**: `front/components/database/designer/TableNode.tsx`

功能：
- 显示表名、字段列表
- 拖拽移动（使用 mouse events）
- 选中状态高亮
- 主键/外键图标显示
- 字段类型颜色标记（复用 datatypes 配置）

### 3.5 创建关系线组件

**文件**: `front/components/database/designer/RelationshipLine.tsx`

功能：
- SVG path 连接两个表
- 贝塞尔曲线或直线
- 基数标记 (1:1, 1:N, N:M)
- 选中状态高亮

### 3.6 创建工具栏组件

**文件**: `front/components/database/designer/ERDiagramToolbar.tsx`

功能：
- 添加表按钮
- 数据库类型切换 (MySQL/PostgreSQL)
- 缩放控制
- 导出 SQL 按钮

### 3.7 创建 SQL 生成器

**目录**: `front/utils/sql-generator/`

文件结构：
- `index.ts` - 策略模式入口 (generateSQL)
- `shared.ts` - 共享工具函数
- `mysql.ts` - MySQL DDL 生成
- `postgresql.ts` - PostgreSQL DDL 生成

复用已有配置：
- `config/datatypes/` - 类型验证
- `config/dbDialects/` - 方言配置

### 3.8 集成到 DatabaseContainer

**文件**: `front/components/database/DatabaseContainer.tsx`

新增 ViewMode: `'erDesigner'`
- 添加切换入口（工具栏或菜单）
- 条件渲染 ERDiagramDesigner 组件

### 3.9 创建主设计器容器

**文件**: `front/components/database/designer/ERDiagramDesigner.tsx`

整合：
- ERDiagramToolbar (顶部)
- ERDiagramCanvas (左侧主区域)
- 属性面板占位 (右侧 - Phase 2)

## 5. 技术要点

### 5.1 拖拽实现

使用原生 mouse events，不引入额外库：

```typescript
const handleMouseDown = (e: React.MouseEvent) => {
  setDragging(true)
  setDragStart({ x: e.clientX - position.x, y: e.clientY - position.y })
}

const handleMouseMove = (e: React.MouseEvent) => {
  if (!dragging) return
  const newX = e.clientX - dragStart.x
  const newY = e.clientY - dragStart.y
  moveTable(tableId, newX, newY)
}
```
