# spec2221: Docker 模块设计文档

## 概述

为 ZWD-OpsBot 实现 Docker 管理模块，支持本地和远程 Docker 环境的统一管理。

## 设计决策

| 决策项 | 选择 | 理由 |
|--------|------|------|
| 连接方式 | 仅 SSH 隧道 | 更安全，复用现有 SSH 连接 |
| 连接关联 | 关联已有 SSH 连接 | 简化配置流程 |
| 第一期范围 | 基础功能 | 容器管理、镜像管理、日志查看 |

## 功能规划

### 第一期 (MVP)

- [x] 容器列表/状态查看
- [x] 容器启动/停止/重启
- [x] 容器日志查看
- [x] 镜像列表
- [x] 镜像拉取/删除
- [x] **概览页面** (已完成)
  - Docker 版本信息
  - 容器统计 (运行中/已停止/总数)
  - 镜像统计 (数量/总大小)
  - 资源使用概览
- [x] **设置页面** (已完成)
  - 镜像加速器配置 (增删改)
  - Docker 守护进程控制 (停止/重启)
  - Docker 存储路径显示
  - Socket 路径显示

### 第二期

- [x] 容器终端
- [x] 网络管理
- [x] 存储卷管理
- [x] Docker Compose 编排
- [x] 资源监控

  - 仓库连接测试
  - 仓库镜像同步
  - 仓库下载限速配置

## 架构设计

### 统一接入方式

```
┌─────────────────────────────────────────────────────────┐
│                    Docker Service                        │
│  ┌─────────────────────────────────────────────────┐    │
│  │              DockerDriver Trait                  │    │
│  │  - list_containers()                            │    │
│  │  - start/stop/restart_container()               │    │
│  │  - get_container_logs()                         │    │
│  │  - list_images()                                │    │
│  │  - pull_image() / remove_image()                │    │
│  └─────────────────────────────────────────────────┘    │
│           ▲                    ▲                         │
│           │                    │                         │
│  ┌────────┴────────┐  ┌───────┴────────┐               │
│  │  LocalDriver    │  │  RemoteDriver  │               │
│  │ (docker.sock)   │  │ (SSH Tunnel)   │               │
│  └─────────────────┘  └────────────────┘               │
└─────────────────────────────────────────────────────────┘
```

### 连接类型

| 类型 | 描述 | 实现方式 |
|------|------|----------|
| Local | 本地 Docker | Unix Socket `/var/run/docker.sock` 或 Windows Named Pipe |
| SSH | 远程 Docker | 关联已有 SSH 连接，建立隧道转发 Docker Socket |

**统一接入的关键**：
- 无论本地还是远程，都通过 Bollard 库的 Docker Client 访问
- 本地：直接连接 socket
- 远程：通过已有 SSH 连接建立隧道，将远程 docker.sock 转发到本地临时端口

use serde::{Deserialize, Serialize};

#[derive(Debug, Clone, Serialize, Deserialize)]
pub enum DockerConnectionType {
    Local,  // 本地 Docker
    SSH,    // 关联 SSH 连接，建立隧道
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct DockerConnectRequest {
    pub connection_id: String,
    pub connection_type: DockerConnectionType,
    pub ssh_connection_id: Option<String>,  // SSH 类型时，关联的 SSH 连接 ID
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct PortMapping {
    pub container_port: u16,
    pub host_port: Option<u16>,
    pub protocol: String,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct ContainerInfo {
    pub id: String,
    pub name: String,
    pub image: String,
    pub status: String,
    pub state: String,  // running, stopped, paused, exited, etc.
    pub created: i64,
    pub ports: Vec<PortMapping>,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct ImageInfo {
    pub id: String,
    pub tags: Vec<String>,
    pub size: u64,
    pub created: i64,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct ContainerLogsRequest {
    pub connection_id: String,
    pub container_id: String,
    pub tail: Option<u32>,
    pub follow: bool,
}

// ========== 概览页面模型 ==========

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct DockerInfo {
    pub version: String,              // Docker 版本
    pub api_version: String,          // API 版本
    pub os: String,                   // 操作系统
    pub arch: String,                 // 架构
    pub kernel_version: String,       // 内核版本
    pub root_dir: String,             // Docker 根目录
    pub storage_driver: String,       // 存储驱动
    pub containers_running: u32,      // 运行中容器数
    pub containers_paused: u32,       // 暂停容器数
    pub containers_stopped: u32,      // 已停止容器数
    pub images: u32,                  // 镜像总数
    pub memory_total: u64,            // 总内存 (bytes)
    pub cpus: u32,                    // CPU 核心数
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct DockerStats {
    pub containers_running: u32,
    pub containers_stopped: u32,
    pub containers_total: u32,
    pub images_count: u32,
    pub images_size: u64,             // 镜像总大小 (bytes)
}

// ========== 设置页面模型 ==========

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct DockerSettings {

    pub socket_path: String,              // Docker Socket 路径
    pub cgroup_driver: String,            // Cgroup 驱动 (cgroupfs/systemd)
    pub live_restore: bool,               // Live Restore 是否启用
    pub ipv6_enabled: bool,               // IPv6 是否启用
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct UpdateRegistryMirrorsRequest {
    pub connection_id: String,
    pub mirrors: Vec<String>,
}

// ========== 仓库管理模型 (新增) ==========

/// 仓库类型
#[derive(Debug, Clone, Serialize, Deserialize)]
pub enum RegistryType {
    DockerHub,      // Docker Hub 官方仓库
    Harbor,         // Harbor 私有仓库
    Nexus,          // Nexus Repository
    Custom,         // 自建仓库 (HTTP/HTTPS Registry)
}

/// 仓库信息
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct RegistryInfo {
    pub id: String,                       // 仓库 ID (UUID)
    pub name: String,                     // 仓库名称
    pub registry_type: RegistryType,      // 仓库类型
    pub url: String,                      // 仓库地址 (如 https://registry.example.com)
    pub username: Option<String>,         // 用户名 (可选)
    pub password: Option<String>,         // 密码 (可选，存储时加密)
    pub download_limit: Option<u32>,      // 下载限速 (KB/s, 可选)
    pub skip_tls_verify: bool,            // 跳过 TLS 证书验证
    pub status: RegistryStatus,           // 连接状态
    pub last_sync_at: Option<i64>,        // 最后同步时间 (Unix timestamp)
    pub created_at: i64,                  // 创建时间
    pub updated_at: i64,                  // 更新时间
}

/// 仓库连接状态
#[derive(Debug, Clone, Serialize, Deserialize)]
pub enum RegistryStatus {
    Connected,      // 已连接
    Disconnected,   // 未连接
    Syncing,        // 同步中
    Error(String),  // 错误
}

/// 创建仓库请求
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct CreateRegistryRequest {
    pub connection_id: String,            // Docker 连接 ID
    pub name: String,
    pub registry_type: RegistryType,
    pub url: String,
    pub username: Option<String>,
    pub password: Option<String>,
    pub download_limit: Option<u32>,
    pub skip_tls_verify: bool,
}

/// 更新仓库请求
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct UpdateRegistryRequest {
    pub connection_id: String,
    pub registry_id: String,
    pub name: Option<String>,
    pub url: Option<String>,
    pub username: Option<String>,
    pub password: Option<String>,
    pub download_limit: Option<u32>,
    pub skip_tls_verify: Option<bool>,
}

/// 同步仓库镜像请求
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct SyncRegistryRequest {
    pub connection_id: String,
    pub registry_id: String,
    pub images: Vec<String>,              // 要同步的镜像列表 (如 ["nginx:latest", "redis:7"])
}

/// 仓库镜像列表
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct RegistryImage {
    pub name: String,                     // 镜像名称 (如 library/nginx)
    pub tags: Vec<String>,                // 标签列表
    pub size: Option<u64>,                // 镜像大小 (bytes)
    pub last_updated: Option<i64>,        // 最后更新时间
}

### 实现说明

**后端**:
- 使用 Bollard 库 (v0.18) 实现 LocalDockerDriver，通过 Unix Socket 连接本地 Docker
- 使用 SSH 命令执行实现 RemoteDockerDriver，通过 SSH 隧道执行远程 docker 命令
- DockerService 管理多个 Docker 会话，支持并发连接
- 容器终端 (exec) 实现:
  - LocalDockerDriver: 使用 Bollard 的 exec API
  - RemoteDockerDriver: 通过 SSH PTY 执行 `docker exec -it`
  - SshService 添加交互式 exec 会话管理 (使用 command channel 模式)
  - 使用 tokio::select! 同时处理用户输入和容器输出
  - 支持终端大小调整 (window_change)

**前端**:
- DockerConnectionDialog: 支持选择本地或远程(SSH)连接类型
- ContainerList: 容器列表，支持启动/停止/重启/删除/查看日志/终端
- ImageList: 镜像列表，支持拉取/删除镜像
- ContainerLogs: 容器日志查看，支持行数选择和自动滚动
- NetworkList: 网络列表，支持创建/删除/清理网络
- VolumeList: 存储卷列表，支持创建/删除/清理存储卷
- ContainerTerminal: 容器终端，基于 XTerm.js 实现
  - 使用 Tauri 事件系统进行双向通信
  - 支持深色/浅色主题自动切换
  - ResizeObserver 实现终端大小自适应 (带 300ms 防抖)
- ContainerStats: 单容器资源监控
  - 实时显示 CPU/内存/网络/磁盘使用情况
  - 3秒自动刷新，支持暂停/恢复
- ComposeList: Compose 项目管理
  - 分栏布局 (左侧项目列表，右侧详情)
  - 快捷操作按钮 (启动/停止/重启)
- ComposeDetail: Compose 项目详情
  - 容器列表 Tab (服务/状态/资源/端口)
  - YAML 编辑器 Tab (语法高亮/保存)
  - 日志查看 Tab (按服务过滤)
- 完整的中英日繁国际化支持

**仓库管理 (第三期)**:
- RegistryList: 仓库列表组件
  - 显示所有配置的仓库 (名称/类型/地址/状态)
  - 支持搜索过滤
  - 快捷操作 (编辑/同步/删除)
  - 连接状态实时显示
- RegistryDialog: 新建/编辑仓库对话框
  - 支持 4 种仓库类型 (Docker Hub/Harbor/Nexus/Custom)
  - 认证配置 (用户名/密码)
  - 高级配置 (限速/TLS 跳过)
  - 连接测试功能
- RegistrySyncDialog: 同步镜像对话框
  - 从远程仓库搜索镜像
  - 多选镜像和标签
  - 同步进度实时显示
- 仓库配置持久化到本地存储

**后端仓库管理实现**:
- 使用 Docker Registry HTTP API V2 与仓库交互
- 支持 Docker Hub 官方 API
- 支持 Harbor/Nexus REST API
- 使用 `docker login` 管理认证
- 使用 `docker pull` 同步镜像
- 仓库配置加密存储
